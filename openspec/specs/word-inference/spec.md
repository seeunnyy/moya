# word-inference Specification

## Purpose
아이의 서툰 발음에서 아이가 의도한 단어를 검수된 단어 데이터 안에서 찾아, 되묻기 화면에서 결과를 보여주고, 확인하거나 고르게 하고, 못 찾으면 물어볼 단어로 넘기는 되묻기 단계를 정의한다. 화면 구성은 Figma 와이어프레임(Section 1)을 따른다.

## Requirements

### Requirement: 발음 기반 후보 찾기
The system SHALL 대상 단어와, 발음 역규칙(ㅅ·ㅆ↔ㄷ·ㄸ 대치, 된소리·거센소리↔예사소리)으로 만든 변형들을 검수된 단어 데이터와 자모 단위로 비교해, 거리가 기준 이하(잠정 2)인 단어를 가까운 순으로 최대 3개 후보로 고른다. 대상 단어가 여러 개면 결과를 합치고 같은 단어는 가장 가까운 거리만 남긴다. 거리가 같으면 단어 데이터 순서를 따른다. (FR-03)

#### Scenario: 역규칙으로 찾음
- **GIVEN** 단어 데이터에 "수박"이 있다
- **WHEN** 대상 단어가 "두박"이다
- **THEN** "수박"이 거리 0의 후보가 된다

#### Scenario: 거센소리 역규칙
- **GIVEN** 단어 데이터에 "태풍"이 있다
- **WHEN** 대상 단어가 "대풍"이다
- **THEN** "태풍"이 거리 0의 후보가 된다

#### Scenario: 받침 생략
- **GIVEN** 단어 데이터에 "저금통"이 있다
- **WHEN** 대상 단어가 "저그통"이다
- **THEN** "저금통"이 거리 1의 후보가 된다

#### Scenario: 후보 수 제한
- **GIVEN** 거리 기준 이하인 단어가 4개 이상이다
- **WHEN** 후보를 고른다
- **THEN** 가장 가까운 3개만 남는다

#### Scenario: 여러 대상 단어 합치기
- **GIVEN** 대상 단어가 "두박"과 "수박" 두 개다
- **WHEN** 후보를 고른다
- **THEN** "수박"은 후보에 한 번만, 거리 0으로 나온다

### Requirement: 되묻기 화면
The system SHALL 인식에 성공해 대상 단어를 꺼내면(부적절 단어 제외) 항상 되묻기 화면(S12, Figma "되묻기 화면")을 먼저 보여준다. 이미지 자리, "이 단어를 물어본 거야?", "모야가 잘 못 들었어요. 아래 단어 중에 골라봐요!", "혹시 이 말이야?"와 후보 미리보기 카드(가로로 최대 3개: 이미지 자리 + 단어 + [들어보기]), 정적인 "다시 말해봐요!" 줄을 두고, 맨 아래에는 결과에 맞는 버튼 하나만 보인다. 후보가 2~3개면 [후보 단어 고르기](→ 후보 카드 선택 S4), 1개면 링크 "단어 확인 질문 보기"(→ 확인 질문 S3), 0개면 링크 "물어볼 단어 안내 보기"(→ 물어볼 단어 안내 S6). 후보가 0개면 "혹시 이 말이야?" 영역을 숨긴다. 미리보기의 [들어보기]는 소리만 내고 이동하지 않는다. "<"는 음성 녹음 화면으로 돌아간다. (FR-03~06)

#### Scenario: 후보 1개
- **WHEN** 아이가 "두박이 뭐야?"라고 묻는다
- **THEN** S12에 수박 미리보기 카드 1개와 링크 "단어 확인 질문 보기"만 보인다
- **AND** 링크를 누르면 S3이 보인다

#### Scenario: 후보 여러 개
- **WHEN** 아이가 "가바가 뭐야?"라고 묻는다
- **THEN** S12에 가방·가발 미리보기 카드와 [후보 단어 고르기]만 보인다
- **AND** [후보 단어 고르기]를 누르면 S4가 보인다

#### Scenario: 후보 없음
- **WHEN** 아이가 "뿌잉뿌잉이 뭐야?"라고 묻는다
- **THEN** S12에 "혹시 이 말이야?" 영역이 없고 링크 "물어볼 단어 안내 보기"만 보인다
- **AND** 링크를 누르면 S6이 보인다

### Requirement: 후보 1개면 확인 질문
The system SHALL 확인 질문 화면(S3)에 원형 이미지 자리, "이 단어 맞나요?", 그 아래 힌트, 카드 박스 안의 단어와 링크 "음성 재생"(단어와 힌트를 소리로)을 보여주고 [네, 맞아요](primary)와 [아니에요](secondary)를 둔다. [네, 맞아요]이면 단어 카드 화면(S5)으로 간다. "<"는 되묻기 화면으로 돌아간다. 모야 대사 "○○ 말하는 거야? <힌트>!"는 화면에 따로 보이지 않고 보조기기와 소리로만 나온다. (FR-04)

#### Scenario: 확인 후 단어 카드
- **GIVEN** "두박이 뭐야?"로 물어 S3에 "수박"이 보인다
- **WHEN** 아이가 [네, 맞아요]를 고른다
- **THEN** 수박 단어 카드 화면(S5)이 보인다

### Requirement: 후보 여러 개면 카드로 고르기
The system SHALL 후보 카드 선택 화면(S4)에 이미지 자리와 "이 중에 네가 물어본 단어가 있어?"를 가로로 두고, 후보 카드를 세로로 최대 3개(단어 + [들어보기] + 힌트) 보여준 뒤 아래에 [여기 없어요](secondary)를 둔다. 카드 자체를 누르면 그 단어로 확정해 단어 카드 화면(S5)으로 가고, [들어보기]는 소리만 내고 선택하지 않는다. 눈에 보이는 고르기 버튼은 따로 두지 않는다. 후보 순서는 거리 순(같으면 데이터 순)이다. "<"는 되묻기 화면으로 돌아간다. (FR-05)

#### Scenario: 카드를 눌러 확정
- **GIVEN** "가바가 뭐야?"로 물어 S4에 가방·가발 카드가 보인다
- **WHEN** 아이가 가발 카드를 누른다
- **THEN** 가발 단어 카드 화면(S5)이 보인다

#### Scenario: 들어보기는 선택이 아님
- **GIVEN** S4가 보인다
- **WHEN** 아이가 가발 카드의 [들어보기]를 누른다
- **THEN** 가발과 힌트가 소리로 나오고 화면은 S4에 그대로 있다

### Requirement: 아니라고 하면 한 번 더 묻기
The system SHALL 확인 질문의 [아니에요]나 후보 화면의 [여기 없어요]를 처음 고르면 음성 녹음 화면(S1)으로 돌아가 한 번 더 말하게 하고, 다시 말한 뒤에도 [아니에요]나 [여기 없어요]를 고르면 물어볼 단어 안내(S6)로 간다. (FR-04, FR-05, FR-06)

#### Scenario: 두 번 아니라고 함
- **GIVEN** "두박이 뭐야?"로 물어 확인 질문이 보인다
- **WHEN** 아이가 [아니에요]를 고르고, 다시 "두박이 뭐야?"로 물어 확인 질문에서 또 [아니에요]를 고른다
- **THEN** 첫 [아니에요] 뒤에는 음성 녹음 화면(S1)으로 돌아간다
- **AND** 두 번째 [아니에요] 뒤에는 물어볼 단어 안내(S6)가 보인다

### Requirement: 물어볼 단어 안내
The system SHALL 물어볼 단어 안내 화면(S6)에 이미지 자리, "물어볼 단어", "모야가 아직 모르는 단어들이에요", 카드 박스(이번에 물은 말 한 줄 + "엄마, 아빠와 함께" + "이 단어들을 알아보세요!"), 이미지 · "보호자 모드에서 확인하기" · 이미지 줄, [내 단어장에 저장하기](primary)를 보여준다. 저장 방식은 word-cards "물어볼 단어 저장 버튼"을 따른다. "<"는 홈(/app)으로 간다. (FR-06)

#### Scenario: 데이터에 없는 말
- **GIVEN** "뿌잉뿌잉이 뭐야?"로 물어 되묻기 화면에서 "물어볼 단어 안내 보기"를 눌렀다
- **WHEN** S6이 열린다
- **THEN** 카드 박스에 "뿌잉뿌잉"이 보이고 [내 단어장에 저장하기]가 보인다

#### Scenario: 홈으로
- **GIVEN** S6이 보인다
- **WHEN** 아이가 "<"를 누른다
- **THEN** 홈(/app)이 보인다
