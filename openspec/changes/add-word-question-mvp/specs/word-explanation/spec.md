# Spec Delta

## Purpose

아이가 고른 단어를 미리 검수한 데이터의 쉬운 설명으로 단어 카드에 보여주고, 모야의 대사를 소리로 들려주는 설명 단계를 정의한다.

## ADDED Requirements

### Requirement: 검수된 데이터로만 설명
The system SHALL 고른 단어를 단어 카드 화면(S5)에 이미지 자리, 단어, 영어 표기(데이터에 있을 때), 카드 박스("○○이/가 뭐야?" + 쉬운 설명 + 이미지 자리)로 보여준다. 설명은 검수된 단어 데이터에서 그대로 가져온다. 예문은 단어 데이터에만 두고 화면에는 보여주지 않는다(와이어프레임 기준). 실행 중에 설명을 새로 만들지 않고, 데이터에 없는 단어는 설명하지 않는다. "<"는 이전 화면(확인 질문 또는 후보 카드 선택)으로 간다. (FR-07, NFR-05)

#### Scenario: 설명 보여주기
- **GIVEN** 아이가 "수박"을 확정했다
- **WHEN** S5가 열린다
- **THEN** 단어 데이터에 있는 수박의 쉬운 설명과 영어 표기가 그대로 보인다
- **AND** 예문은 보이지 않는다

#### Scenario: 영어 표기가 없는 단어
- **GIVEN** 단어 데이터에 영어 표기가 없다
- **WHEN** S5가 열린다
- **THEN** 영어 표기 줄이 보이지 않는다

### Requirement: 모야의 대사를 소리로 들려주기
The system SHALL 화면이 바뀔 때 모야의 대사를 기기 음성으로 읽어 준다. 대사는 화면에 따로 보이지 않고(화면 글자는 Figma 문구뿐) 보조기기용 알림 영역에만 둔다. 단어 카드의 [🔊 들어보기], 확인 질문의 링크 "음성 재생", 되묻기·후보 카드의 [들어보기]를 누르면 해당 단어와 설명(또는 힌트)을 읽어 준다. 기기가 음성 출력을 지원하지 않으면 글자만 보여주고 흐름을 계속한다. (FR-08)

#### Scenario: 대사 읽기
- **GIVEN** 음성 출력을 지원하는 기기다
- **WHEN** 확인 질문 화면이 열린다
- **THEN** "수박 말하는 거야? <힌트>!"가 소리로 나오고 보조기기 알림 영역에도 들어간다

#### Scenario: 다시 듣기
- **GIVEN** S5에 설명이 보인다
- **WHEN** 아이가 [🔊 들어보기]를 누른다
- **THEN** 설명을 처음부터 다시 읽는다

#### Scenario: 녹음 중에는 읽지 않음
- **GIVEN** 모야가 대사를 읽고 있다
- **WHEN** 아이가 [녹음 시작]을 누른다
- **THEN** 읽던 대사를 멈추고, 듣는 중·생각 중에는 아무것도 읽지 않는다

#### Scenario: 음성 출력 미지원
- **GIVEN** 음성 출력을 지원하지 않는 기기다
- **WHEN** 모야의 대사가 나온다
- **THEN** 오류 없이 다음 단계로 진행할 수 있다
