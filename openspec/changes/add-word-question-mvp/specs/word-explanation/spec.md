# Spec Delta

## Purpose

아이가 고른 단어를 미리 검수한 데이터의 쉬운 설명과 예문으로 보여주고, 모야의 대사를 소리로 들려주는 설명 단계를 정의한다.

## ADDED Requirements

### Requirement: 검수된 데이터로만 설명
The system SHALL 고른 단어의 쉬운 설명(한두 문장)과 일상 예문 1개를 검수된 단어 데이터에서 그대로 보여준다(S5). 실행 중에 설명을 새로 만들지 않고, 데이터에 없는 단어는 설명하지 않는다. (FR-07, NFR-05)

#### Scenario: 설명 보여주기
- **GIVEN** 아이가 "수박"을 확정했다
- **WHEN** S5가 열린다
- **THEN** 단어 데이터에 있는 수박의 쉬운 설명과 예문이 그대로 보인다

#### Scenario: 들은 상황 함께 보여주기
- **GIVEN** 아이가 상황 버튼 [TV]를 고른 뒤 "가발"을 확정했다
- **WHEN** S5가 열린다
- **THEN** 설명과 함께 TV에서 들었다는 내용이 보인다

### Requirement: 모야의 대사를 소리로 들려주기
The system SHALL 모야의 대사와 설명을 화면 글자와 같은 문장으로 기기 음성으로 읽어 주고, [다시 듣기]를 누르면 다시 읽어 준다. 기기가 음성 출력을 지원하지 않으면 글자만 보여주고 흐름을 계속한다. (FR-08)

#### Scenario: 대사 읽기
- **GIVEN** 음성 출력을 지원하는 기기다
- **WHEN** 확인 질문 "수박 말하는 거야?"가 화면에 나온다
- **THEN** 같은 문장이 소리로 나온다

#### Scenario: 다시 듣기
- **GIVEN** S5에 설명이 보인다
- **WHEN** 아이가 [다시 듣기]를 누른다
- **THEN** 설명을 처음부터 다시 읽는다

#### Scenario: 음성 출력 미지원
- **GIVEN** 음성 출력을 지원하지 않는 기기다
- **WHEN** 모야의 대사가 나온다
- **THEN** 글자만 보이고 오류 없이 다음 단계로 진행할 수 있다
