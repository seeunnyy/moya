# Spec Delta

## Purpose

아이가 모르는 단어를 말로(또는 마이크를 못 쓸 때 글자·예시 버튼으로) 묻고, 그 질문에서 물어본 단어를 꺼내는 입력 단계를 정의한다. 화면 구성과 이동은 Figma 와이어프레임(Section 1)과 Manyfast '새 플로우 1'을 따른다.

## ADDED Requirements

### Requirement: 홈에서 음성 녹음 화면으로
The system SHALL 아이 모드 홈(/app)의 [모야한테 물어보기]를 누르면 권한 안내를 거치지 않고 음성 녹음 화면(/app/ask, S1)으로 간다. 홈의 링크 "마이크 사용 방법 안내"는 마이크 권한 안내(/app/mic, S10)로 간다. (FR-01)

#### Scenario: 홈에서 바로 녹음 화면
- **WHEN** 아이가 홈에서 [모야한테 물어보기]를 누른다
- **THEN** 음성 녹음 화면(S1)이 보인다

### Requirement: 마이크 권한 안내
The system SHALL 마이크 권한 안내 화면(S10)에 이미지 자리, "마이크 권한 허용", "모야가 너의 목소리를 들으려면" / "마이크 권한이 필요해!", [권한 허용하기](primary), [나중에 할래](secondary)를 둔다. [권한 허용하기]는 브라우저 마이크 권한을 요청해 허용되면 음성 녹음 화면으로, 거부되면 음성 녹음 화면의 폴백 상태(E1)로 간다. [나중에 할래]는 홈으로 간다. "<"는 이전 화면으로 간다(이전 화면이 없으면 홈). (FR-01, FR-13)

#### Scenario: 권한 허용
- **WHEN** 아이가 [권한 허용하기]를 누르고 브라우저에서 허용한다
- **THEN** 음성 녹음 화면(S1)이 보인다

#### Scenario: 나중에
- **WHEN** 아이가 [나중에 할래]를 누른다
- **THEN** 홈이 보인다

### Requirement: 마이크로 질문 녹음과 인식
The system SHALL 음성 녹음 화면(S1)에 이미지 자리, "뭐가 궁금해?", 파형 이미지 자리, [녹음 시작](primary), 링크 "다시 말하기"를 둔다. [녹음 시작]을 누르면, 마이크 권한을 아직 묻지 않았으면 권한 안내(S10)로 보내고, 허용돼 있으면 바로 녹음한다. 듣는 중·생각 중은 새 화면이 아니라 같은 화면에서 버튼 글자만 [녹음 시작] → [그만하기] → "생각 중…"(비활성)으로 바뀐다. 아이가 [그만하기]를 누르거나 최대 녹음 시간이 지나면 녹음을 멈추고 음성인식 결과(인식 후보 1개 이상)를 대상 단어 추출로 넘긴다. 인식에 성공하면 되묻기 화면(S12), 인식 실패·추출 실패면 다시 말하기 안내(E2), 부적절 단어면 부적절 단어 안내(E3)로 간다. 링크 "다시 말하기"는 다시 말하기 안내(E2)로 간다. "<"는 홈으로 간다. (FR-01)

#### Scenario: 권한을 아직 묻지 않음
- **GIVEN** 이 기기에서 마이크 권한을 아직 묻지 않았다
- **WHEN** 아이가 [녹음 시작]을 누른다
- **THEN** 마이크 권한 안내(S10)가 보인다

#### Scenario: 질문이 인식됨
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 아이가 [녹음 시작]을 누르고 "공룡이 뭐야?"라고 말한 뒤 [그만하기]를 누른다
- **THEN** 같은 화면에서 버튼이 [그만하기] → "생각 중…"으로 바뀐다
- **AND** 인식 텍스트 "공룡이 뭐야"로 되묻기 화면(S12)이 보인다

#### Scenario: 인식 후보가 여러 개
- **GIVEN** 음성인식이 인식 후보를 2개 이상 돌려준다
- **WHEN** 인식이 끝난다
- **THEN** 모든 인식 후보가 대상 단어 추출로 넘어간다

#### Scenario: 최대 녹음 시간
- **WHEN** 녹음을 시작하고 [그만하기]를 누르지 않는다
- **THEN** 최대 녹음 시간이 지나면 녹음을 멈추고 [그만하기]를 누른 것과 같이 진행된다

#### Scenario: 녹음 중 화면을 떠남
- **WHEN** 녹음 중에 아이가 "<"로 홈에 간다
- **THEN** 녹음을 멈추고 마이크를 닫으며, 녹음한 내용은 보내지 않는다

#### Scenario: 다시 말하기 링크
- **WHEN** 아이가 링크 "다시 말하기"를 누른다
- **THEN** 다시 말하기 안내(E2)가 보인다

### Requirement: 다시 말하기 안내
The system SHALL 음성인식 요청이 실패하거나(네트워크 오류 포함) 결과가 비어 있거나 대상 단어를 꺼내지 못하면 다시 말하기 안내(E2)에 이미지 자리, "다시 말해줄래?", "처음부터 다시 시도해봐!", [다시 녹음하기](primary)를 보여준다. [다시 녹음하기]는 다시 말하기 횟수를 그대로 두고 음성 녹음 화면(S1)으로 돌아간다. "<"는 이전 화면으로 간다. (NFR-07)

#### Scenario: 네트워크 오류
- **GIVEN** 네트워크가 끊겨 있다
- **WHEN** 아이가 질문을 녹음한다
- **THEN** E2 "다시 말해줄래?"와 [다시 녹음하기]가 보인다

### Requirement: 마이크를 쓸 수 없을 때
The system SHALL 마이크를 쓸 수 없으면(권한 거부, 마이크 없음, 브라우저 미지원, http 접속) 음성 녹음 화면(S1)의 [녹음 시작] 아래에 텍스트 입력과 서툰 발음 예시 버튼을 보여준다(E1). 마이크를 쓸 수 있으면 이 둘은 숨긴다. (FR-13, NFR-07)

#### Scenario: 권한 거부 후 텍스트로 계속
- **GIVEN** 마이크 권한이 거부돼 있다
- **WHEN** 음성 녹음 화면이 열린다
- **THEN** [녹음 시작] 아래에 텍스트 입력과 예시 버튼이 보인다
- **AND** 텍스트로 "공룡이 뭐야?"를 입력하면 마이크로 물은 것과 같은 흐름으로 진행된다

#### Scenario: 평소에는 숨김
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 음성 녹음 화면이 열린다
- **THEN** 텍스트 입력과 예시 버튼이 보이지 않는다

### Requirement: 서툰 발음 예시 버튼
The system SHALL 폴백 상태(E1)의 예시 버튼을 누르면 그 문장을 인식 텍스트로 삼아 같은 흐름을 진행한다. (FR-13)

#### Scenario: 마이크 없이 되묻기 재현
- **GIVEN** 음성 녹음 화면이 폴백 상태다
- **WHEN** 아이가 예시 버튼 [두박이 뭐야?]를 누른다
- **THEN** 마이크를 쓰지 않고 되묻기 화면(S12)을 거쳐 "수박" 확인 질문(S3)까지 진행할 수 있다

### Requirement: 대상 단어 추출
The system SHALL 인식 텍스트에서 "○○이 뭐야", "○○가 뭐야", "○○ 뭐야" 형태의 ○○을 대상 단어로 꺼낸다. 인식 후보가 여러 개면 각각에서 꺼낸다. 어느 후보에서도 꺼내지 못하면 E2를 보여준다. (FR-02)

#### Scenario: 조사 '이'가 붙은 질문
- **WHEN** 인식 텍스트가 "공룡이 뭐야?"이다
- **THEN** 대상 단어는 "공룡"이다

#### Scenario: 조사 '가'가 붙은 질문
- **WHEN** 인식 텍스트가 "가바가 뭐야"이다
- **THEN** 대상 단어는 "가바"이다

#### Scenario: 질문 형태가 아님
- **WHEN** 인식 텍스트가 "공룡"이거나 비어 있다
- **THEN** E2 "다시 말해줄래?"가 보인다

### Requirement: 음성인식 키 보호
The system MUST 음성인식 서비스의 API 키를 서버에서만 사용하고, 브라우저로 전달되는 코드와 응답에 포함하지 않는다. (NFR-03)

#### Scenario: 클라이언트에 키 없음
- **WHEN** 배포용 빌드 결과물에서 클라이언트로 전달되는 파일을 검사한다
- **THEN** 음성인식 API 키 값이 어디에도 나오지 않는다
