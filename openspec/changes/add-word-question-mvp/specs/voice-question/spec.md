# Spec Delta

## Purpose

아이가 모르는 단어를 말로(또는 마이크를 못 쓸 때 글자·예시 버튼으로) 묻고, 그 질문에서 물어본 단어를 꺼내는 입력 단계를 정의한다.

## ADDED Requirements

### Requirement: 홈에서 묻기 화면으로
The system SHALL 아이 모드 홈(/app)에 [모야한테 물어보기]를 두고, 누르면 마이크 권한 안내(/app/mic)로 간다. 권한 안내에는 "모야가 너의 목소리를 들으려면 마이크 권한이 필요해!"와 [권한 허용하기], [나중에 할래]를 둔다. [권한 허용하기]는 브라우저 마이크 권한을 요청해 허용되면 묻기 화면(/app/ask, S1)으로, 거부되면 E1로 간다. [나중에 할래]는 마이크 없이 묻기 화면(S1)으로 가서 텍스트 입력·예시 버튼으로 진행하게 한다. 이 기기에서 마이크 권한이 이미 허용돼 있으면 홈에서 권한 안내를 건너뛰고 바로 S1로 간다. (FR-01, FR-13)

#### Scenario: 마이크 없이 시작
- **WHEN** 아이가 홈에서 [모야한테 물어보기]를 누르고 권한 안내에서 [나중에 할래]를 누른다
- **THEN** 묻기 화면(S1)이 보이고 텍스트 입력과 예시 버튼으로 물을 수 있다

#### Scenario: 이미 허용된 기기
- **GIVEN** 이 기기에서 마이크 권한이 이미 허용돼 있다
- **WHEN** 아이가 홈에서 [모야한테 물어보기]를 누른다
- **THEN** 권한 안내 없이 묻기 화면(S1)이 보인다

#### Scenario: 묻기 흐름에서 홈으로
- **GIVEN** 묻기 흐름의 어느 화면이든 보인다
- **WHEN** 아이가 헤더의 "<"를 누른다
- **THEN** 흐름이 처음으로 돌아가고 홈(/app)이 보인다

### Requirement: 마이크로 질문 녹음과 인식
The system SHALL 묻기 화면(S1, "뭐가 궁금해?")의 [녹음 시작]을 누르면 녹음을 시작하고, 아이가 [그만하기]를 누르거나 최대 녹음 시간이 지나면 녹음을 멈춘다. 녹음이 끝나면 음성인식 결과(인식 후보 1개 이상)를 대상 단어 추출로 넘긴다. (FR-01)

#### Scenario: 질문이 인식됨
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 아이가 [녹음 시작]을 누르고 "공룡이 뭐야?"라고 말한다
- **THEN** 녹음 중에는 '듣는 중', 인식 중에는 '생각 중' 상태가 보인다
- **AND** 인식 텍스트 "공룡이 뭐야"로 다음 단계가 진행된다

#### Scenario: 인식 후보가 여러 개
- **GIVEN** 음성인식이 인식 후보를 2개 이상 돌려준다
- **WHEN** 인식이 끝난다
- **THEN** 모든 인식 후보가 대상 단어 추출로 넘어간다

#### Scenario: [그만하기]로 녹음 끝내기
- **WHEN** 녹음 중에 아이가 [그만하기]를 누른다
- **THEN** 녹음을 멈추고 '생각 중'을 거쳐 녹음한 질문으로 다음 단계가 진행된다

#### Scenario: 최대 녹음 시간
- **WHEN** 녹음을 시작하고 [그만하기]를 누르지 않는다
- **THEN** 최대 녹음 시간이 지나면 녹음을 멈추고 [그만하기]를 누른 것과 같이 진행된다

#### Scenario: 녹음 중 화면을 떠남
- **WHEN** 녹음 중에 아이가 "<"로 홈에 간다
- **THEN** 녹음을 멈추고 마이크를 닫으며, 녹음한 내용은 보내지 않는다

### Requirement: 음성인식 실패 처리
The system SHALL 음성인식 요청이 실패하거나(네트워크 오류 포함) 결과가 비어 있으면 "다시 말해줄래?" / "처음부터 다시 시도해봐!" 화면(E2)을 보여주고, [다시 녹음하기]·텍스트 입력·예시 버튼으로 계속할 수 있게 한다. [다시 녹음하기]는 다시 말하기 횟수를 그대로 두고 묻기 화면(S1)으로 돌아간다. (NFR-07)

#### Scenario: 네트워크 오류
- **GIVEN** 네트워크가 끊겨 있다
- **WHEN** 아이가 질문을 녹음한다
- **THEN** E2 "다시 말해줄래?"가 보인다
- **AND** [다시 녹음하기], 텍스트 입력, 예시 버튼이 보인다

### Requirement: 마이크 권한 거부 처리
The system SHALL 마이크 권한 요청이 거부되면([권한 허용하기] 또는 [녹음 시작]에서) 마이크를 쓸 수 없다는 화면(E1)을 보여주고, 텍스트 입력과 예시 버튼으로 계속할 수 있게 한다. (FR-13, NFR-07)

#### Scenario: 권한 거부 후 텍스트로 계속
- **GIVEN** 마이크 권한이 거부돼 있다
- **WHEN** 아이가 권한 안내의 [권한 허용하기]나 묻기 화면의 [녹음 시작]을 누른다
- **THEN** E1이 보인다
- **AND** 텍스트로 "공룡이 뭐야?"를 입력하면 마이크로 물은 것과 같은 흐름으로 진행된다

### Requirement: 서툰 발음 예시 버튼
The system SHALL 묻기 화면과 E1·E2에 서툰 발음 질문 예시 버튼을 보여주고, 누르면 그 문장을 인식 텍스트로 삼아 같은 흐름을 진행한다. (FR-13)

#### Scenario: 마이크 없이 되묻기 재현
- **WHEN** 아이가 예시 버튼 [두박이 뭐야?]를 누른다
- **THEN** 마이크를 쓰지 않고 "수박 말하는 거야?" 확인 질문(S3)까지 진행된다

### Requirement: 대상 단어 추출
The system SHALL 인식 텍스트에서 "○○이 뭐야", "○○가 뭐야", "○○ 뭐야" 형태의 ○○을 대상 단어로 꺼낸다. 인식 후보가 여러 개면 각각에서 꺼낸다. 어느 후보에서도 꺼내지 못하면 E2를 보여준다. (FR-02)

#### Scenario: 조사 '이'가 붙은 질문
- **WHEN** 인식 텍스트가 "공룡이 뭐야?"이다
- **THEN** 대상 단어는 "공룡"이다

#### Scenario: 조사 '가'가 붙은 질문
- **WHEN** 인식 텍스트가 "가바가 뭐야"이다
- **THEN** 대상 단어는 "가바"이다

#### Scenario: 질문 형태가 아님
- **WHEN** 인식 텍스트가 "공룡"이거나 비어 있다
- **THEN** E2 "다시 말해줄래?"가 보인다

### Requirement: 음성인식 키 보호
The system MUST 음성인식 서비스의 API 키를 서버에서만 사용하고, 브라우저로 전달되는 코드와 응답에 포함하지 않는다. (NFR-03)

#### Scenario: 클라이언트에 키 없음
- **WHEN** 배포용 빌드 결과물에서 클라이언트로 전달되는 파일을 검사한다
- **THEN** 음성인식 API 키 값이 어디에도 나오지 않는다
