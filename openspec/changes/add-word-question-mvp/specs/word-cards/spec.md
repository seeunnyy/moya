# Spec Delta

## Purpose

아이가 배운 단어(단어 카드)와 모야가 찾지 못한 단어(물어볼 단어)를 이 기기에 저장하고, 단어장에서 다시 볼 수 있게 한다.

## ADDED Requirements

### Requirement: 단어 카드 자동 저장
The system SHALL 설명 화면(S5)이 열리면 단어, 사전 뜻, 쉬운 설명, 예문, 들은 상황(있을 때), 아이가 처음 말한 발음(인식 텍스트), 만든 날짜를 담은 단어 카드를 이 기기에 저장하고, 저장됐다는 표시를 보여준다. (FR-09)

#### Scenario: 카드 저장
- **GIVEN** 아이가 "두박이 뭐야?"로 물어 "수박"을 확정했다
- **WHEN** S5가 열린다
- **THEN** 저장 완료 표시가 보인다
- **AND** 저장된 카드의 단어는 "수박", 처음 말한 발음은 "두박"이다

#### Scenario: 저장 실패
- **GIVEN** 브라우저 저장소를 쓸 수 없다
- **WHEN** 카드를 저장하려 한다
- **THEN** 화면이 깨지지 않고 흐름을 계속 진행할 수 있다

### Requirement: 단어장 목록
The system SHALL 단어장(S7)에서 저장한 단어 카드와 물어볼 단어를 목록으로 보여준다. 새로고침하거나 다시 접속해도 같은 기기에서는 목록이 남아 있다. 저장된 것이 없으면 빈 상태 안내를 보여준다. (FR-10)

#### Scenario: 새로고침 후에도 남음
- **GIVEN** "공룡" 카드를 저장했다
- **WHEN** 단어장을 열고 새로고침한다
- **THEN** 공룡 카드가 목록에 보인다

#### Scenario: 물어볼 단어도 보임
- **GIVEN** "뿌잉뿌잉"이 물어볼 단어로 저장돼 있다
- **WHEN** 단어장을 연다
- **THEN** 물어볼 단어 목록에 "뿌잉뿌잉"이 보인다

#### Scenario: 저장된 것이 없음
- **GIVEN** 이 기기에 저장된 카드와 물어볼 단어가 없다
- **WHEN** 단어장을 연다
- **THEN** 빈 상태 안내가 보인다

#### Scenario: 저장소를 읽을 수 없음
- **GIVEN** 저장된 데이터가 손상됐거나 저장소를 읽을 수 없다
- **WHEN** 단어장을 연다
- **THEN** 화면이 깨지지 않고 빈 상태 안내가 보인다
