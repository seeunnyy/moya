# Spec Delta

## Purpose

아이가 배운 단어(단어 카드)와 모야가 찾지 못한 단어(물어볼 단어)를 이 기기에 저장하고, 단어 카드 목록에서 다시 볼 수 있게 한다.

## ADDED Requirements

### Requirement: 단어 카드 저장 버튼
The system SHALL 단어 카드 화면(S5)에 [🔊 들어보기](secondary)와 [내 단어장에 저장하기](primary)를 나란히 두고, 아이가 저장을 누르면 단어, 사전 뜻, 쉬운 설명, 예문, 아이가 처음 말한 발음(인식 텍스트), 만든 날짜를 담은 단어 카드를 이 기기에 저장한다. 저장 결과는 버튼 글자로만 보여준다: 성공하면 "저장했어!"(비활성), 실패하면 "다시 저장하기"(다시 누를 수 있음). 스크린 리더용 알림은 화면에 보이지 않게 둔다. 누르지 않고 화면을 떠나면 저장하지 않는다. 아래에 링크 "단어 카드 목록으로"(→ /app/cards)를 둔다. (FR-09)

#### Scenario: 버튼으로 카드 저장
- **GIVEN** 아이가 "두박이 뭐야?"로 물어 "수박"을 확정해 S5가 보인다
- **WHEN** 아이가 [내 단어장에 저장하기]를 누른다
- **THEN** 버튼이 "저장했어!"로 바뀌고 비활성이 된다
- **AND** 저장된 카드의 단어는 "수박", 처음 말한 발음은 "두박"이다

#### Scenario: 저장하지 않고 나감
- **GIVEN** S5가 보인다
- **WHEN** [내 단어장에 저장하기]를 누르지 않고 "단어 카드 목록으로"나 "<"로 화면을 떠난다
- **THEN** 단어 카드 목록에 그 카드가 생기지 않는다

#### Scenario: 저장 실패
- **GIVEN** 브라우저 저장소를 쓸 수 없다
- **WHEN** 아이가 [내 단어장에 저장하기]를 누른다
- **THEN** 화면이 깨지지 않고 버튼이 "다시 저장하기"로 바뀐다
- **AND** 다시 눌러 성공하면 "저장했어!"로 바뀐다

### Requirement: 물어볼 단어 저장 버튼
The system SHALL 물어볼 단어 안내 화면(S6)에 [내 단어장에 저장하기](primary)를 두고, 아이가 누르면 아이가 말한 대상 단어(인식 텍스트)와 만든 날짜를 물어볼 단어로 이 기기에 저장한다. 저장 결과는 버튼 글자로만 보여준다: 성공 "적어 뒀어!"(비활성), 실패 "다시 저장하기". 누르지 않고 화면을 떠나면 저장하지 않는다. 부적절 단어 안내(E3)에는 이 버튼을 두지 않는다(content-safety). (FR-06)

#### Scenario: 버튼으로 물어볼 단어 저장
- **GIVEN** "뿌잉뿌잉이 뭐야?"로 물어 S6이 보인다
- **WHEN** 아이가 [내 단어장에 저장하기]를 누른다
- **THEN** 버튼이 "적어 뒀어!"로 바뀌고 비활성이 된다
- **AND** 단어 카드 목록의 물어볼 단어 목록에 "뿌잉뿌잉"이 보인다

#### Scenario: 저장하지 않고 나감
- **GIVEN** S6이 보인다
- **WHEN** [내 단어장에 저장하기]를 누르지 않고 "<"로 화면을 떠난다
- **THEN** 물어볼 단어 목록에 그 단어가 생기지 않는다

#### Scenario: 물어볼 단어 저장 실패
- **GIVEN** 브라우저 저장소를 쓸 수 없다
- **WHEN** 아이가 [내 단어장에 저장하기]를 누른다
- **THEN** 화면이 깨지지 않고 버튼이 "다시 저장하기"로 바뀌며, 다시 누를 수 있다

### Requirement: 단어 카드 목록
The system SHALL 단어 카드 목록(S7, /app/cards)에 "내 단어 카드", "학습 상태" Select, 칩 [전체] [새 단어] [복습 중] [완료], 저장한 카드의 2열 그리드(이미지 자리 + 단어 + 상태 글자)를 보여주고, 그 아래에 물어볼 단어 목록을 같은 카드 스타일로 보여준다. Select와 칩은 같은 필터 값을 공유한다. 반복 학습이 베타라 지금은 모든 카드의 상태가 "새 단어"이고, [복습 중]·[완료] 필터 결과는 비어 있는 것이 정상이다. 카드를 누르면 그 카드의 상세(/app/cards/[id])로 간다. 새로고침하거나 다시 접속해도 같은 기기에서는 목록이 남아 있다. 저장된 것이 없으면 빈 상태 안내를 보여준다. (FR-10)

#### Scenario: 새로고침 후에도 남음
- **GIVEN** "수박" 카드를 저장했다
- **WHEN** 목록을 열고 새로고침한다
- **THEN** 수박 카드가 "새 단어" 상태로 보인다

#### Scenario: 필터
- **GIVEN** 카드가 1개 이상 저장돼 있다
- **WHEN** 칩 [복습 중]을 누른다
- **THEN** Select도 "복습 중"으로 바뀌고 카드 그리드가 비어 있다
- **AND** 칩 [전체]나 [새 단어]를 누르면 카드가 다시 보인다

#### Scenario: 물어볼 단어도 보임
- **GIVEN** "뿌잉뿌잉"이 물어볼 단어로 저장돼 있다
- **WHEN** 목록을 연다
- **THEN** 물어볼 단어 목록에 "뿌잉뿌잉"이 보인다

#### Scenario: 저장된 것이 없음
- **GIVEN** 이 기기에 저장된 카드와 물어볼 단어가 없다
- **WHEN** 목록을 연다
- **THEN** 빈 상태 안내가 보인다

#### Scenario: 저장소를 읽을 수 없음
- **GIVEN** 저장된 데이터가 손상됐거나 저장소를 읽을 수 없다
- **WHEN** 목록을 연다
- **THEN** 화면이 깨지지 않고 빈 상태 안내가 보인다

#### Scenario: 카드를 눌러 상세로
- **GIVEN** "수박" 카드가 저장돼 있다
- **WHEN** 목록에서 수박 카드를 누른다
- **THEN** /app/cards/<그 카드의 id>로 가서 수박 카드 상세가 보인다

### Requirement: 단어 카드 상세
The system SHALL /app/cards/[id]에서 그 id(저장된 단어 카드의 id)의 카드를 단어 카드 화면(S5)과 같은 모양으로 보여주되, [내 단어장에 저장하기] 대신 처음 물은 말("처음엔 '두박'이라고 물어봤어") 한 줄을 둔다. "<"는 단어 카드 목록으로 간다. 저장된 카드 중 그 id가 없으면 "그 카드를 찾을 수 없어" 안내와 링크 "단어 카드 목록으로"를 보여준다(자동으로 이동하지 않는다). (FR-10)

#### Scenario: 상세 보기
- **GIVEN** "두박이 뭐야?"로 물어 "수박" 카드가 저장돼 있다
- **WHEN** 그 카드의 상세를 연다
- **THEN** 수박의 쉬운 설명과 "처음엔 '두박'이라고 물어봤어"가 보이고 [내 단어장에 저장하기]는 보이지 않는다

#### Scenario: 없는 카드
- **WHEN** 저장된 적 없는 id로 /app/cards/[id]를 연다
- **THEN** "그 카드를 찾을 수 없어" 안내와 "단어 카드 목록으로"가 보인다

#### Scenario: 새로고침
- **GIVEN** 카드 상세가 열려 있다
- **WHEN** 새로고침한다
- **THEN** 같은 카드 상세가 다시 보인다
