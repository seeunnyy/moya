# Spec Delta

## Purpose

글을 막 배우는 아이가 휴대폰 세로 화면에서 혼자 쓸 수 있도록, 아이 화면 전체에 적용되는 모바일·접근성 기준을 정한다. 화면 모양은 Figma 와이어프레임(Section 1, 프레임 폭 390px)을 따른다.

## ADDED Requirements

### Requirement: 모바일 세로 화면
The system SHALL 앱 틀을 최대 390px 폭으로 가운데 정렬하고, 375px 폭 세로 화면에서도 모든 화면을 가로 스크롤 없이 보여주며, 모바일 Chrome과 Safari에서 동작한다. (NFR-01)

#### Scenario: 375px 폭
- **WHEN** 375px 폭에서 모든 아이 화면을 차례로 연다
- **THEN** 어느 화면에서도 가로 스크롤이 생기지 않는다

### Requirement: 글자가 있는 버튼과 넓은 터치 영역
The system SHALL 버튼에 짧은 글자를 함께 쓰고, 보이는 크기는 Figma 그대로(버튼 33~35px, 링크 17px) 두되 누르는 영역은 투명하게 최소 48×48px로 넓힌다. 와이어프레임 단계 예외로 헤더의 뒤로 버튼은 "<"만 보이고 aria-label("이전 화면" 또는 "홈으로")을 단다. (NFR-08)

#### Scenario: 버튼 점검
- **WHEN** 아이 화면의 버튼을 모두 확인한다
- **THEN** "<"를 뺀 모든 버튼에 글자가 있고, 누르는 영역이 48×48px 이상이다
- **AND** "<"에는 보조기기가 읽을 이름이 있다

### Requirement: 키보드와 보조기기 지원
The system SHALL 모든 버튼을 키보드로 조작할 수 있게 하고 포커스를 눈에 보이게 한다. 모야의 대사는 화면에 보이지 않는 알림 영역(aria-live)에 두어 바뀔 때마다 보조기기가 읽게 하고, 화면마다 본문 제목을 h1으로 둔다. 헤더의 화면 이름은 h1이 아니다. (NFR-08)

#### Scenario: 키보드만으로 진행
- **WHEN** 키보드만 써서 폴백 상태에서 "두박이 뭐야?" 입력부터 카드 저장까지 진행한다
- **THEN** 모든 단계를 진행할 수 있고, 지금 포커스된 버튼이 눈에 보인다

#### Scenario: 대사 읽힘
- **GIVEN** 스크린 리더가 켜져 있다
- **WHEN** 모야의 대사가 바뀐다
- **THEN** 바뀐 대사를 스크린 리더가 읽는다

### Requirement: 자동으로 넘어가지 않음
The system SHALL 화면을 시간 제한으로 자동으로 넘기지 않고, 아이가 버튼을 눌러야 다음 단계로 간다. (03 §3)

#### Scenario: 기다려도 그대로
- **GIVEN** 확인 질문 화면(S3)이 보인다
- **WHEN** 아무것도 누르지 않고 1분을 기다린다
- **THEN** 화면이 그대로 S3에 머문다

### Requirement: 화면 이동
The system SHALL 홈(/app)과 단어 카드 목록(/app/cards)에만 하단 탭 [홈] [단어 카드] [보호자]를 두고 헤더에 뒤로 버튼을 두지 않는다. 나머지 화면은 헤더의 "<"로 이동한다: 음성 녹음·물어볼 단어 안내·보호자 화면은 홈으로, 카드 상세는 목록으로, 그 밖의 화면은 이전 화면으로 간다. 헤더 가운데에는 Figma의 화면 이름("음성 녹음 화면" 등)을 보여준다. 화면이 바뀌면 그 화면의 h1으로 포커스를 옮긴다. (NFR-08)

#### Scenario: 하단 탭
- **GIVEN** 홈이 보인다
- **WHEN** 하단 탭 [단어 카드], [보호자]를 차례로 누르고 보호자 화면에서 "<"를 누른다
- **THEN** /app/cards, /parent, /app으로 차례로 이동한다

#### Scenario: 이전 화면
- **GIVEN** 되묻기 화면에서 "단어 확인 질문 보기"로 확인 질문 화면에 왔다
- **WHEN** "<"를 누른다
- **THEN** 되묻기 화면이 보인다

#### Scenario: 베타 기능 표시
- **WHEN** 홈의 [복습하기] 카드나 복습 배너를 누른다
- **THEN** 아무 일도 일어나지 않는다
