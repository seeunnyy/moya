# Spec Delta

## Purpose

글을 막 배우는 아이가 휴대폰 세로 화면에서 혼자 쓸 수 있도록, 아이 화면 전체에 적용되는 모바일·접근성 기준을 정한다.

## ADDED Requirements

### Requirement: 모바일 세로 화면
The system SHALL 375px 폭 세로 화면에서 모든 화면(S0~S7, S9~S11, E1, E2)을 가로 스크롤 없이 보여주고, 모바일 Chrome과 Safari에서 동작한다. (NFR-01)

#### Scenario: 375px 폭
- **WHEN** 375px 폭에서 홈(S9), 권한 안내(S10), S1~S7, 카드 상세(S11)를 차례로 연다
- **THEN** 어느 화면에서도 가로 스크롤이 생기지 않는다

### Requirement: 글자가 있는 큰 버튼
The system SHALL 모든 버튼에 짧은 글자를 함께 쓰고(아이콘만 있는 버튼 금지), 터치 영역을 최소 48×48px로 한다. (NFR-08)

#### Scenario: 버튼 점검
- **WHEN** 아이 화면의 버튼을 모두 확인한다
- **THEN** 모든 버튼에 글자가 있고, 터치 영역이 48×48px 이상이다

### Requirement: 키보드와 보조기기 지원
The system SHALL 모든 버튼을 키보드로 조작할 수 있게 하고 포커스를 눈에 보이게 한다. 모야의 대사 영역은 보조기기가 바뀔 때마다 읽도록 하고, 화면마다 의미 있는 제목을 둔다. (NFR-08)

#### Scenario: 키보드만으로 진행
- **WHEN** 키보드만 써서 "공룡이 뭐야?" 입력부터 카드 저장까지 진행한다
- **THEN** 모든 단계를 진행할 수 있고, 지금 포커스된 버튼이 눈에 보인다

#### Scenario: 대사 읽힘
- **GIVEN** 스크린 리더가 켜져 있다
- **WHEN** 모야의 대사가 바뀐다
- **THEN** 바뀐 대사를 스크린 리더가 읽는다

### Requirement: 자동으로 넘어가지 않음
The system SHALL 화면을 시간 제한으로 자동으로 넘기지 않고, 아이가 버튼을 눌러야 다음 단계로 간다. (03 §3)

#### Scenario: 기다려도 그대로
- **GIVEN** 확인 질문 화면(S3)이 보인다
- **WHEN** 아무것도 누르지 않고 1분을 기다린다
- **THEN** 화면이 그대로 S3에 머문다

### Requirement: 화면 이동
The system SHALL 홈(/app)과 단어 카드 목록(/app/cards)에만 하단 탭 [홈] [단어 카드] [보호자]를 두고, 나머지 아이 화면은 헤더의 "<"로 돌아가게 한다. "<"는 권한 안내·묻기 흐름에서는 홈으로, 카드 상세에서는 단어 카드 목록으로 간다. 화면이 바뀌면 그 화면의 제목(h1)으로 포커스를 옮긴다. (NFR-08)

#### Scenario: 하단 탭
- **GIVEN** 홈이 보인다
- **WHEN** 하단 탭 [단어 카드], [보호자], [홈]을 차례로 누른다
- **THEN** /app/cards, /parent, /app으로 차례로 이동한다

#### Scenario: 베타 기능 표시
- **WHEN** 홈의 [복습하기] 타일을 본다
- **THEN** "베타" 표시와 함께 눌러도 아무 일도 일어나지 않는(비활성) 상태로 보인다
