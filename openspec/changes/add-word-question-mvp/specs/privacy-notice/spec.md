# Spec Delta

## Purpose

아동 서비스로서 아이 음성과 기록이 어떻게 처리되는지 최소한으로 다루고, 그 사실을 화면에서 분명히 알린다.

## ADDED Requirements

### Requirement: 음성 원본 미저장
The system MUST 아이의 음성 원본을 서버나 기기에 저장하지 않고, 인식이 끝나면 버린다. 이 기기에는 인식 텍스트와 단어 카드 정보만 저장한다. (NFR-04)

#### Scenario: 저장 내용 확인
- **GIVEN** 아이가 마이크로 질문해 카드가 저장됐다
- **WHEN** 이 기기의 저장 데이터를 확인한다
- **THEN** 인식 텍스트와 카드 정보만 있고 음성 데이터는 없다

### Requirement: 저장·전송 고지
The system SHALL 묻기 화면(S1)과 단어장(S7)에서, 목소리는 글자로 바꾸기 위해 음성인식 서비스로 전송되고 저장되지 않으며 물어본 단어는 이 기기에만 저장된다는 안내를 볼 수 있게 한다. (NFR-09)

#### Scenario: 고지 확인
- **WHEN** 아이나 보호자가 S1에서 고지 영역을 연다
- **THEN** "목소리는 글자로 바꾸는 데만 쓰고 저장하지 않아요. 물어본 단어는 이 기기에만 저장돼요."와 같은 뜻의 안내가 보인다

#### Scenario: 단어장에서도 확인
- **WHEN** S7에서 고지 영역을 연다
- **THEN** S1과 같은 안내가 보인다
