# Spec Delta

## Purpose

아이의 서툰 발음에서 아이가 의도한 단어를 검수된 단어 데이터 안에서 찾아, 되물어 확인하거나 고르게 하고, 못 찾으면 물어볼 단어로 넘기는 되묻기 단계를 정의한다.

## ADDED Requirements

### Requirement: 발음 기반 후보 찾기
The system SHALL 대상 단어와, 발음 역규칙(ㅅ·ㅆ↔ㄷ·ㄸ 대치, 된소리·거센소리↔예사소리)으로 만든 변형들을 검수된 단어 데이터와 자모 단위로 비교해, 거리가 기준 이하(잠정 2)인 단어를 가까운 순으로 최대 3개 후보로 고른다. 대상 단어가 여러 개면 결과를 합치고 같은 단어는 가장 가까운 거리만 남긴다. (FR-03)

#### Scenario: 역규칙으로 찾음
- **GIVEN** 단어 데이터에 "수박"이 있다
- **WHEN** 대상 단어가 "두박"이다
- **THEN** "수박"이 거리 0의 후보가 된다

#### Scenario: 거센소리 역규칙
- **GIVEN** 단어 데이터에 "태풍"이 있다
- **WHEN** 대상 단어가 "대풍"이다
- **THEN** "태풍"이 거리 0의 후보가 된다

#### Scenario: 받침 생략
- **GIVEN** 단어 데이터에 "저금통"이 있다
- **WHEN** 대상 단어가 "저그통"이다
- **THEN** "저금통"이 거리 1의 후보가 된다

#### Scenario: 후보 수 제한
- **GIVEN** 거리 기준 이하인 단어가 4개 이상이다
- **WHEN** 후보를 고른다
- **THEN** 가장 가까운 3개만 남는다

#### Scenario: 여러 대상 단어 합치기
- **GIVEN** 대상 단어가 "두박"과 "수박" 두 개다
- **WHEN** 후보를 고른다
- **THEN** "수박"은 후보에 한 번만, 거리 0으로 나온다

### Requirement: 후보 1개면 확인 질문
The system SHALL 후보가 1개면 "이 단어 맞나요?" 확인 질문 화면(S3)에 그 단어와 힌트를 보여주고("○○ 말하는 거야? <힌트>!" 대사), [네, 맞아요]와 [아니에요]를 제공한다. [네, 맞아요]이면 단어 카드 화면(S5)으로 간다. (FR-04)

#### Scenario: 확인 후 설명
- **GIVEN** "공룡이 뭐야?"로 물어 후보가 "공룡" 하나다
- **WHEN** S3이 열린다
- **THEN** "공룡 말하는 거야? 아주 옛날에 살던 큰 동물!"처럼 단어와 힌트가 보인다
- **AND** 아이가 [네, 맞아요]를 고르면 공룡 단어 카드 화면(S5)으로 간다

### Requirement: 후보 여러 개면 상황 단서로 고르기
The system SHALL 후보가 2~3개면 "어디서 들었어?"와 상황 버튼(TV / 책 / 어른 말 / 유치원·학교 / 모르겠어, 잠정)을 먼저 보여준다. 상황을 고르면 거리가 같은 후보 중 그 상황 태그를 가진 단어를 앞에 두고, "이 중에 네가 물어본 단어가 있어?" 후보 카드 선택 화면에 후보를 힌트와 함께 보여준다. 카드마다 [들어보기](단어와 힌트를 들려줌)와 [이거야!](확정)를 두고, 아래에 [여기 없어요]를 둔다. (FR-05)

#### Scenario: 상황으로 순서가 바뀜
- **GIVEN** "가바가 뭐야?"로 물어 가방(유치원·학교)과 가발(TV)이 둘 다 거리 1이다
- **WHEN** 아이가 [TV]를 고른다
- **THEN** 가발 카드가 첫 번째로 보인다

#### Scenario: 다른 상황
- **GIVEN** 같은 후보다
- **WHEN** 아이가 [유치원·학교]를 고른다
- **THEN** 가방 카드가 첫 번째로 보인다

#### Scenario: 상황을 모름
- **GIVEN** 같은 후보다
- **WHEN** 아이가 [모르겠어]를 고른다
- **THEN** 후보 카드가 거리 순서로 보이고, 들은 상황은 기록되지 않는다

#### Scenario: 카드 확정
- **GIVEN** 아이가 [TV]를 골라 후보 카드가 보인다
- **WHEN** 가발 카드의 [이거야!]를 누른다
- **THEN** 가발 단어 카드 화면(S5)으로 가고, 들은 상황 'TV'가 함께 넘어간다

### Requirement: 아니라고 하면 한 번 더 묻기
The system SHALL 확인 질문의 [아니에요]나 후보 화면의 [여기 없어요]를 처음 고르면 묻기 화면(S1)으로 돌아가 한 번 더 말하게 하고, 다시 말한 뒤에도 [아니에요]나 [여기 없어요]를 고르면 물어볼 단어로 넘긴다. (FR-04, FR-05, FR-06)

#### Scenario: 두 번 아니라고 함
- **GIVEN** "공룡이 뭐야?"로 물어 확인 질문이 보인다
- **WHEN** 아이가 [아니에요]를 고르고, 다시 "공룡이 뭐야?"로 물은 뒤 또 [아니에요]를 고른다
- **THEN** 첫 [아니에요] 뒤에는 묻기 화면(S1)으로 돌아간다
- **AND** 두 번째 [아니에요] 뒤에는 물어볼 단어 화면(S6)이 보이고, [내 단어장에 저장하기]를 누르면 "공룡"이 물어볼 단어로 저장된다

### Requirement: 후보가 없으면 물어볼 단어
The system SHALL 거리 기준 이하인 후보가 하나도 없으면 물어볼 단어 안내 화면(S6, "모야가 아직 모르는 단어들이에요" / "엄마, 아빠와 함께 이 단어들을 알아보세요!")을 보여주고, 아이가 말한 대상 단어와 [내 단어장에 저장하기], 보조 버튼 [또 물어보기](묻기 화면 S1)를 둔다. 저장 방식은 word-cards "물어볼 단어 저장 버튼"을 따른다. (FR-06)

#### Scenario: 데이터에 없는 말
- **WHEN** 아이가 "뿌잉뿌잉이 뭐야?"라고 묻는다
- **THEN** S6에 "뿌잉뿌잉"과 [내 단어장에 저장하기]가 보인다

#### Scenario: 물어볼 단어 안내에서 이어가기
- **GIVEN** S6이 보인다
- **WHEN** 아이가 [또 물어보기]를 누른다
- **THEN** 새 질문으로 묻기 화면(S1)이 보이고, 다시 말하기 횟수가 처음으로 돌아간다
