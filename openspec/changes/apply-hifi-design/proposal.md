# Proposal: 새 피그마 완성 디자인 전면 적용 (apply-hifi-design)

## Why

지금 코드와 스펙은 회색 와이어프레임(피그마 `rJZjG6ik2Q2ffj1BiK20U8`, 폭 390px) 기준이다. PM이 완성 디자인(피그마 `U3GaTLJGAbLj5qgTTJiodv` '디자인' 페이지, 64장, 프레임 402×874)을 확정했다. 11/5 1차 배포·11/6 사용성 테스트 전에 화면 구성·버튼·이동·스타일을 이 피그마와 똑같이 맞추고, 피그마에 새로 들어온 기능(보호자 가입, 맥락 질문, 별·미션, 오늘의 단어, 보호자가 단어 알려주기)을 MVP 범위에서 동작하게 한다. 기준 결정은 `planning/prompts/design-v2-2026-10-09.md` A-2·A-3.

## What Changes

- **화면 기준 교체**: 앱 틀 최대 폭 390 → 402px. 402px에서 피그마와 일치시키고, 375·390px에서는 가로 넘침·잘림이 없게 한다. 피그마의 상태바(위 62px)와 홈 인디케이터는 만들지 않는다. 색·글꼴(Jua, NanumSquareRound, Noto Sans KR)·모서리·그림자를 피그마 값으로 바꾼다.
- **아이 모드 흐름 재구성** (**BREAKING**: 화면·주소가 바뀜): 홈(2-1)의 마이크를 누르면 바로 듣는 중(2-2) → 생각 중(2-3) → 확인 질문(2-4)으로 간다. 되묻기 화면(S12)과 [아니에요] 두 번 규칙은 없어지고, [아니야] → "어디서 들었어?"(2-5) → 후보 고르기(2-6) → 뜻 알려주기(2-9) → 카드 획득(2-10)으로 바뀐다. 못 알아들으면 다시 말해줄래(2-7), 모르는 단어는 물어볼 단어(2-8).
- **맥락 질문 되살리기**: 2-5에서 고른 '들은 곳'으로 같은 거리 후보의 순서를 정한다(결정 3).
- **카드에 예문 보여주기**: 카드 획득·카드 상세에 검수 데이터의 예문을 보인다(결정 4). 저장 버튼은 없어지고 카드·물어볼 단어는 자동으로 모인다.
- **별·오늘의 미션·로켓 도장**: 헤더 미션 별 3칸과 별 개수, 오늘의 미션 시트(2-0), 세 번째 카드 → 미션 성공(2-13, 2-14), 내 정보(3-4), 내 별과 로켓(3-5). 이 기기에 저장한다(결정 5).
- **지구 사전·오늘의 단어**: 단어 카드 목록이 지구 사전(3-1, 필터 없음)으로 바뀌고, 오늘의 단어(3-3, 3-3a)가 생긴다.
- **보호자 가입·로그인·비밀번호(기기 저장 mock)**: 시작(1-1)부터 가입·프로필·음성 동의·보호자 비밀번호·마이크 권한·아이 모드 시작(1-8)까지의 온보딩과 로그인(1-0)을 만든다. 서버 계정·카카오 연동·메일 발송은 없다(결정 1).
- **보호자 모드**: 비밀번호 잠금(5-1~5-1b), 보호자 홈(5-2), 물어볼 단어와 단어 알려주기(5-3, 5-3a, 결정 6), 설정·프로필·비밀번호 변경·음성 기록 삭제·동의 철회·로그아웃(5-4~5-9). '녹음 듣기'는 숨긴다(결정 2).
- **예외 화면**: 연결이 끊겼어요(E-1), 마이크가 꺼져 있어요(E-2). 1-7 마이크 권한 팝업은 진짜 브라우저 권한 창을 쓴다.
- **베타 제외**: ④ 베타 8장(4-1~4-6)은 만들지 않는다. 베타 표시 항목(복습 배너, 주간 리포트, 구독 등)은 보이기만 하고 눌러도 동작하지 않는다(결정 7).
- **이관된 작업**: 이전 change의 11.1 랜딩(→ 1-1 시작), 11.2 실기기 데모, 10.5 실제 STT(보류 유지)를 이 change에서 마무리한다.
- 범위 밖: 실제 카카오 로그인·서버 계정·메일 발송, 아이 음성 원본 저장, 복습·주간 리포트·구독(④), LLM 실시간 설명, 사전 API, 결제.

## Capabilities

### New Capabilities
- `guardian-account`: 이 기기에만 저장하는 보호자 가입·로그인·로그아웃, 아이 프로필, 보호자 비밀번호(잠금·재설정·변경), 보호자 홈과 설정
- `daily-mission`: 별 개수, 오늘의 미션(모르는 말 3개 물어보기), 미션 성공 보상, 로켓 도장과 연속 기록, 내 정보·내 별과 로켓 화면
- `today-word`: 날마다 하나씩 보여주는 오늘의 단어와 지구 사전에 넣기
- `parent-word-teaching`: 보호자가 물어볼 단어에 검수된 단어를 알려 주고, 다음에 같은 말이 들리면 그 단어를 먼저 보여주기

### Modified Capabilities
- `child-accessibility`: 기준 폭 402px, 피그마 누르는 영역(마이크 118 · 주요 버튼 60 · 카드 114), 보이는 말풍선 대사, 인식 후 자동 진행, 하단 탭 3개와 헤더 이동, 베타 항목 표시
- `voice-question`: 홈 마이크로 바로 듣기, 듣는 중·생각 중 화면, 온보딩 마이크 권한(진짜 권한 창), 다시 말해줄래(2-7), 연결 끊김(E-1)·마이크 꺼짐(E-2), 폴백 위치
- `word-inference`: 되묻기 화면·두 번 아니라고 하기 제거, 확인 질문(2-4)·어디서 들었어?(2-5)·후보 고르기(2-6)·물어볼 단어(2-8) 재정의, 들은 곳·보호자가 알려준 단어로 후보 순서 정하기
- `word-explanation`: 뜻 알려주기(2-9)와 카드 획득(2-10) 화면, 예문 보이기, 말풍선 스피커
- `word-cards`: 저장 버튼 제거(카드·물어볼 단어 자동 저장), 지구 사전(3-1)과 카드 상세(3-2), 같은 단어 다시 물었을 때
- `content-safety`: 부적절 단어 안내를 새 화면 스타일로
- `privacy-notice`: 고지 위치를 /parent에서 음성 수집 동의(1-4)·설정으로 옮김, 동의·동의 철회·음성 기록(인식 글자) 삭제

## Impact

- 화면·주소: `/`·`/login`·`/signup/*`(온보딩), `/app`(2-0~2-14, E-1, E-2), `/app/dictionary`·`/app/dictionary/[id]`·`/app/today`·`/app/me`·`/app/me/stars`, `/parent/*`(5-1~5-9). 옛 `/app/ask`·`/app/mic`·`/app/cards*`는 지운다. 표는 design.md.
- 코드: `askFlow` 상태 기계 재작성, 공통 컴포넌트 교체, `src/lib/storage`에 계정·프로필·동의·비밀번호·별·미션·오늘의 단어·알려준 단어 저장 추가, `src/types`의 `HeardContext` 값과 `WordEntry` 필드(그림·말풍선 설명) 변경, mock 단어·STT mock 순서를 피그마 시연 단어로 교체. `src/lib/pronunciation`은 순수 함수로 유지하고 알려준 단어 연결은 입력으로 받는다.
- 스타일·에셋: `globals.css` `@theme` 토큰 교체, Jua(next/font/google), NanumSquareRound(next/font/local, 파일 출처·라이선스 확인 후), 캐릭터·단어 그림·아이콘을 `public/`에 저장.
- 의존성: 새 패키지 없음(글꼴 파일은 확인 후 추가). 외부 API는 그대로 STT 하나(현재 mock).
- 문서: CLAUDE.md, HANDOFF.md, docs/DESIGN.md, `openspec/config.yaml` context는 이 change 제안과 함께 고치고, planning/md-design 02~05는 각 그룹에서 고친다.
