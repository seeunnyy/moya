# Spec Delta

## MODIFIED Requirements

### Requirement: 부적절한 단어 안내
The system SHALL 대상 단어가 부적절 단어 목록에 있으면 후보 찾기·확인 질문·설명을 하지 않고, 아이 모드 화면 스타일(헤더, 모야, 말풍선, 하단 탭)로 "그 말은 엄마·아빠한테 물어보자!" 안내와 다시 묻는 마이크 버튼을 보여준다. 피그마에 없는 화면이라 배치는 다시 말해줄래(2-7)를 따르되 [글자 카드로 고를래]는 두지 않는다. 이 단어는 단어 카드나 물어볼 단어로 저장하지 않고, 별·미션에도 세지 않는다. 부적절 단어 목록의 내용과 판별 기준은 별도로 정한다. (NFR-06)

#### Scenario: 목록에 있는 단어
- **GIVEN** 부적절 단어 목록에 어떤 단어가 있다
- **WHEN** 아이가 그 단어로 "○○이 뭐야?"라고 묻는다
- **THEN** "그 말은 엄마·아빠한테 물어보자!" 안내와 마이크 버튼이 보인다
- **AND** 지구 사전과 물어볼 단어에 그 단어가 추가되지 않고 별 개수가 그대로다

#### Scenario: 목록에 없는 단어
- **WHEN** 아이가 "저금통이 뭐야?"라고 묻는다
- **THEN** 안내 없이 평소처럼 확인 질문 단계로 진행된다
