# Spec Delta

## MODIFIED Requirements

### Requirement: 음성 원본 미저장
The system MUST 아이의 음성 원본을 서버나 기기에 저장하지 않고, 인식이 끝나면 버린다. 선택 동의("서비스 개선을 위한 음성 활용")를 켜도 마찬가지다. 이 기기에는 인식 텍스트와 단어 카드 정보만 저장한다. 피그마의 '녹음 듣기'와 '내가 말한 소리' 재생은 녹음 대신 인식된 글자를 기기 음성으로 읽어 준다. (NFR-04)

#### Scenario: 저장 내용 확인
- **GIVEN** 아이가 마이크로 질문해 카드를 얻었다
- **WHEN** 이 기기의 저장 데이터를 확인한다
- **THEN** 인식 텍스트와 카드 정보만 있고 음성 데이터는 없다

#### Scenario: 선택 동의를 켜도 저장 안 함
- **GIVEN** 보호자가 서비스 개선 음성 활용에 동의했다
- **WHEN** 아이가 마이크로 질문한다
- **THEN** 음성 데이터는 기기와 서버 어디에도 저장되지 않는다

### Requirement: 저장·전송 고지
The system SHALL 음성 수집 동의 화면(1-4)에서 아이 목소리를 어디에 쓰는지(질문을 알아듣는 데만 쓰고, 기록 삭제·동의 철회는 설정에서 할 수 있음)를 피그마 문구로 알리고, 약관 보기(1-2a)에서 약관을 보여준다. 아이 화면에는 저장·전송 안내를 두지 않는다. 옛 보호자 화면(/parent)의 고지 문단은 없앤다. (NFR-09)

#### Scenario: 고지 확인
- **WHEN** 보호자가 가입 중 음성 수집 동의 화면(1-4)을 연다
- **THEN** 목소리를 질문을 알아듣는 데만 쓴다는 안내와 설정에서 지우거나 철회할 수 있다는 안내가 보인다

#### Scenario: 아이 화면에는 없음
- **WHEN** 홈(2-1)과 지구 사전(3-1)을 연다
- **THEN** 저장·전송 안내가 보이지 않는다

## ADDED Requirements

### Requirement: 음성 수집 동의
The system SHALL 음성 수집 동의 화면(1-4)에 [필수] 음성 수집·이용 동의와 [선택] 서비스 개선 음성 활용 동의 체크박스를 두고, 필수 동의를 켜야 [동의하고 다음]으로 진행하게 한다. 동의 상태와 시각은 이 기기에만 저장한다. 약관 줄의 "›"는 약관 보기(1-2a)로 간다. 선택 동의는 설정(5-4)의 토글과 같은 값이다.

#### Scenario: 필수 동의 없이 진행 불가
- **GIVEN** 1-4에서 필수 동의가 꺼져 있다
- **WHEN** 보호자가 [동의하고 다음]을 누른다
- **THEN** 다음 화면으로 가지 않는다

#### Scenario: 선택 동의는 설정과 같음
- **GIVEN** 1-4에서 선택 동의를 켜고 가입을 마쳤다
- **WHEN** 설정(5-4)을 연다
- **THEN** "서비스 개선에 목소리 활용 (선택)" 토글이 켜져 있다

### Requirement: 음성 기록 삭제
The system SHALL 설정의 "음성 기록 삭제 요청"을 누르면 확인 창(5-7)을 띄우고, [지우기]를 누르면 이 기기에 저장된 인식 텍스트 기록(물어볼 단어의 물은 말, 카드의 '내가 말한 소리')을 지운 뒤 설정(5-4a)으로 돌아가 완료 알림을 보여준다. 단어 카드는 그대로 남는다. [취소]나 창 바깥을 누르면 아무것도 지우지 않고 설정으로 돌아간다.

#### Scenario: 기록 지우기
- **GIVEN** 물어볼 단어 '저구멍'과 '내가 말한 소리'가 있는 저금통 카드가 있다
- **WHEN** 보호자가 5-7에서 [지우기]를 누른다
- **THEN** 설정 화면에 삭제 완료 알림이 보이고, 저금통 카드는 남지만 '저구멍'과 카드의 '내가 말한 소리'는 더 이상 보이지 않는다

#### Scenario: 취소
- **WHEN** 보호자가 5-7에서 [취소]를 누른다
- **THEN** 아무것도 지워지지 않고 설정(5-4)이 보인다

### Requirement: 음성 수집 동의 철회
The system SHALL 설정의 "음성 수집 동의 철회"를 누르면 확인 창(5-8)을 띄우고, [철회하기]를 누르면 필수 동의를 끈 뒤 음성 수집 동의 화면(1-4)으로 보낸다. 필수 동의가 꺼져 있는 동안에는 마이크로 묻지 않는다(다시 동의하면 이어서 쓴다). [취소]나 창 바깥은 설정으로 돌아간다.

#### Scenario: 철회 후 다시 동의
- **WHEN** 보호자가 5-8에서 [철회하기]를 누른다
- **THEN** 음성 수집 동의 화면(1-4)이 보인다
- **AND** 필수 동의를 다시 켜고 진행하면 아이가 다시 마이크로 물을 수 있다
