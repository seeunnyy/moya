# Spec Delta

## MODIFIED Requirements

### Requirement: 단어 카드 목록
The system SHALL 지구 사전(3-1)에 헤더, "지구 사전"과 "모은 카드 N장", 복습 배너(베타 표시, 누르면 아무 일도 없음), 모은 카드의 3열 그리드(그림, 단어, 복습 별 3칸, 오늘 모은 카드의 NEW 표시, 다 앎 체크), 하단 탭을 보여준다. 필터는 두지 않는다. 반복 학습이 베타라 새로 모은 카드는 모두 '새 카드' 상태다. 카드를 누르면 그 카드의 상세(3-2)로 간다. 물어볼 단어는 지구 사전에 보이지 않고 보호자 모드(5-3)에서 본다. 새로고침하거나 다시 접속해도 같은 기기에서는 목록이 남아 있다. 모은 카드가 없을 때의 화면은 피그마에 없어 design.md에서 정한다. (FR-10)

#### Scenario: 새로고침 후에도 남음
- **GIVEN** 저금통 카드를 모았다
- **WHEN** 지구 사전을 열고 새로고침한다
- **THEN** 저금통 카드가 보이고 "모은 카드 1장"이다

#### Scenario: 필터
- **WHEN** 지구 사전을 연다
- **THEN** 옛 "학습 상태" Select와 필터 칩이 보이지 않는다

#### Scenario: 물어볼 단어도 보임
- **GIVEN** "저구멍"이 물어볼 단어로 저장돼 있다
- **WHEN** 지구 사전을 연다
- **THEN** 지구 사전에는 "저구멍"이 없고, 보호자 모드의 물어볼 단어(5-3)에서 보인다

#### Scenario: 저장된 것이 없음
- **GIVEN** 이 기기에 모은 카드가 없다
- **WHEN** 지구 사전을 연다
- **THEN** "모은 카드 0장"과 빈 상태 화면(design.md)이 보인다

#### Scenario: 저장소를 읽을 수 없음
- **GIVEN** 저장된 데이터가 손상됐거나 저장소를 읽을 수 없다
- **WHEN** 지구 사전을 연다
- **THEN** 화면이 깨지지 않고 카드가 없는 상태로 보인다

#### Scenario: 카드를 눌러 상세로
- **GIVEN** 저금통 카드가 있다
- **WHEN** 지구 사전에서 저금통 카드를 누른다
- **THEN** 저금통 카드 상세(3-2)가 보인다

#### Scenario: 복습 배너
- **WHEN** 복습 배너를 누른다
- **THEN** 아무 화면으로도 이동하지 않는다

### Requirement: 단어 카드 상세
The system SHALL 카드 상세(3-2)에 헤더, "<"와 "지구 사전", 카드 획득(2-10)과 같은 카드(상태 표시와 날짜, 그림, 단어, '내가 말한 소리' 칩, 쉬운 설명, 예문, 복습 별과 안내 줄)를 보여주고, 아래 버튼은 카드 상태에 따라 피그마대로 둔다: 새 카드 "복습은 며칠 뒤에 열려요"(비활성), 복습 중 "베타 · 복습은 베타 기능이에요" + [모야한테 설명해 볼래](눌러도 이동 없음), 다 앎 "다 앎 도장 받았어!"(비활성). "<"는 지구 사전으로 간다. 저장된 카드 중 그 id가 없으면 지구 사전으로 돌려보낸다. (FR-10)

#### Scenario: 상세 보기
- **GIVEN** "저금통이 뭐야?"로 물어 저금통 카드를 모았다
- **WHEN** 그 카드의 상세를 연다
- **THEN** 저금통의 쉬운 설명·예문과 '내가 말한 소리' "저금통"이 보이고 아래 버튼은 "복습은 며칠 뒤에 열려요"(비활성)다

#### Scenario: 없는 카드
- **WHEN** 저장된 적 없는 id로 카드 상세를 연다
- **THEN** 지구 사전(3-1)이 보인다

#### Scenario: 새로고침
- **GIVEN** 카드 상세가 열려 있다
- **WHEN** 새로고침한다
- **THEN** 같은 카드 상세가 다시 보인다

## ADDED Requirements

### Requirement: 카드 자동 획득
The system SHALL 뜻 알려주기(2-9)에서 [알았어!]를 눌러 카드 획득(2-10)이 열리면, 단어, 쉬운 설명, 예문, 아이가 처음 말한 발음(인식 텍스트), 들은 곳(고른 경우), 만든 날짜를 담은 카드를 이 기기에 저장하고 별 1개를 준다(daily-mission). 지구 사전에 같은 단어 카드가 이미 있으면 새 카드를 만들지 않고 별·미션도 늘리지 않으며, 2-10에는 그 카드를 보여준다. 저장에 실패해도 화면은 깨지지 않고 흐름을 계속한다. (FR-09)

#### Scenario: 카드 모으기
- **GIVEN** 지구 사전에 저금통이 없다
- **WHEN** 아이가 저금통 2-9에서 [알았어!]를 누른다
- **THEN** 2-10에 "저금통 카드 모았다! 별 1개 받았어!"가 보이고 별 개수가 1 늘어난다
- **AND** 지구 사전에 저금통 카드가 생긴다

#### Scenario: 이미 있는 단어
- **GIVEN** 지구 사전에 저금통 카드가 있다
- **WHEN** 아이가 다시 저금통을 확정해 2-10이 열린다
- **THEN** 지구 사전의 저금통 카드는 1장 그대로이고 별 개수도 그대로다

#### Scenario: 저장 실패
- **GIVEN** 브라우저 저장소를 쓸 수 없다
- **WHEN** 2-10이 열린다
- **THEN** 화면이 깨지지 않고 [또 물어볼래]로 계속할 수 있다

### Requirement: 물어볼 단어 자동 저장
The system SHALL 물어볼 단어(2-8)가 열리면 아이가 말한 대상 단어(인식 텍스트)와 만든 시각을 물어볼 단어로 이 기기에 저장한다. 같은 말이 이미 물어볼 단어에 있으면 다시 추가하지 않는다. 부적절 단어는 저장하지 않는다(content-safety). 저장한 물어볼 단어는 보호자 모드(5-2, 5-3)에서 본다. (FR-06)

#### Scenario: 물어볼 단어 저장
- **WHEN** 아이가 "저구멍이 뭐야?"로 물어 2-8이 열린다
- **THEN** 보호자 모드의 물어볼 단어(5-3)에 '저구멍'이 보인다

## REMOVED Requirements

### Requirement: 단어 카드 저장 버튼
**Reason**: 새 피그마의 카드 획득(2-10)에는 저장 버튼이 없고, 카드를 모으면 별을 준다.
**Migration**: "카드 자동 획득"으로 대체. 기존 `moya.cards.v1` 카드는 그대로 읽는다.

### Requirement: 물어볼 단어 저장 버튼
**Reason**: 새 피그마의 물어볼 단어(2-8)는 "물어볼 단어 상자에 넣었어"로 자동 저장을 알린다.
**Migration**: "물어볼 단어 자동 저장"으로 대체. 기존 `moya.pending.v1`은 그대로 읽는다.
