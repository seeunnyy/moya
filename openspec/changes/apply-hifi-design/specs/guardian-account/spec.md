# Spec Delta

## Purpose

보호자가 이 기기에 계정과 아이 프로필을 만들고, 보호자 비밀번호로 보호자 모드(홈·설정)를 잠그고 여는 흐름을 정한다. MVP에서는 서버 계정·외부 로그인 연동 없이 모든 정보를 이 기기에만 저장한다.

## ADDED Requirements

### Requirement: 첫 진입 분기
The system SHALL 앱 첫 주소로 들어오면, 이 기기에 로그인된 보호자 계정이 없으면 시작(1-1)을, 있으면 홈(2-1)을 보여준다. 계정이 없는데 아이·보호자 화면 주소로 바로 들어오면 시작(1-1)으로 보낸다.

#### Scenario: 처음 쓰는 기기
- **GIVEN** 이 기기에 계정 기록이 없다
- **WHEN** 앱 첫 주소를 연다
- **THEN** 시작(1-1) "모야, 모야?"와 [시작하기], [이미 계정이 있어요]가 보인다

#### Scenario: 가입한 기기
- **GIVEN** 이 기기에서 가입을 마쳤다
- **WHEN** 앱 첫 주소를 연다
- **THEN** 홈(2-1)이 보인다

### Requirement: 기기 저장 가입
The system SHALL 보호자 가입(1-2)에서 [카카오로 시작하기]와 이메일·비밀번호 + [다음] 두 길을 피그마대로 보여주고, 둘 다 실제 외부 연동 없이 이 기기에만 가입 정보를 저장한 뒤 아이 프로필(1-3)로 간다. [다음]은 이메일·비밀번호를 채우고 필수 약관 3개를 켜야 동작한다. 약관 줄의 "›"는 약관 보기(1-2a)로, 1-2a의 [확인했어요]와 "<"는 이전 화면으로 간다. 가입 정보는 서버로 보내지 않고, 이메일 계정 비밀번호는 기기에도 저장하지 않는다(design.md).

#### Scenario: 이메일로 가입
- **WHEN** 보호자가 이메일·비밀번호를 쓰고 필수 약관 3개를 켠 뒤 [다음]을 누른다
- **THEN** 아이 프로필(1-3)이 보이고, 네트워크로 가입 정보가 전송되지 않는다

#### Scenario: 카카오 버튼
- **WHEN** 보호자가 [카카오로 시작하기]를 누른다
- **THEN** 카카오 화면 없이 아이 프로필(1-3)이 보인다

#### Scenario: 필수 약관을 안 켬
- **GIVEN** 필수 약관 하나가 꺼져 있다
- **WHEN** 보호자가 [다음]을 누른다
- **THEN** 다음 화면으로 가지 않는다

### Requirement: 아이 프로필
The system SHALL 아이 프로필(1-3)에서 아이 별명과 나이 칩(5세·6세·7세·8세 중 하나)을 받고, "아이 모드에서 이렇게 불러요 '○○야, 안녕!'" 미리보기를 별명에 맞춰 바꾼다. [다음]은 별명과 나이를 채워야 동작하며 음성 수집 동의(1-4)로 간다. 프로필은 이 기기에만 저장하고, 보호자 모드의 아이 프로필 수정(5-5)에서 같은 값을 고쳐 [저장하기]하면 설정(5-4)으로 돌아간다.

#### Scenario: 프로필 만들기
- **WHEN** 보호자가 별명 "지우"와 [7세]를 고르고 [다음]을 누른다
- **THEN** 음성 수집 동의(1-4)가 보이고, 내 정보(3-4)에 "지우"와 "만 7세"가 나온다

#### Scenario: 프로필 수정
- **GIVEN** 5-5가 열려 있다
- **WHEN** 나이를 [8세]로 바꾸고 [저장하기]를 누른다
- **THEN** 설정(5-4)의 아이 프로필 줄이 "지우 · 만 8세"로 보인다

### Requirement: 보호자 비밀번호 만들기
The system SHALL 보호자 비밀번호 만들기(1-5)에서 키패드로 4자리를 받고, 4자리를 채우면 확인(1-5a)으로 넘어가 한 번 더 받는다. 두 값이 같으면 이 기기에 저장하고 마이크 권한 안내(1-6)로 간다. 다르면 1-5a를 비우고 다시 받는다(틀렸을 때 문구는 design.md).

#### Scenario: 같은 번호 두 번
- **WHEN** 보호자가 1-5에서 "1234", 1-5a에서 "1234"를 누른다
- **THEN** 마이크 권한 안내(1-6)가 보인다

#### Scenario: 다른 번호
- **WHEN** 보호자가 1-5에서 "1234", 1-5a에서 "1243"을 누른다
- **THEN** 1-5a가 비워지고 1-6으로 가지 않는다

### Requirement: 아이 모드 시작
The system SHALL 아이 모드 시작(1-8)에 "준비 끝!", "이제 ○○에게 휴대폰을 건네주세요.", 보호자 메뉴 위치 안내, [아이 모드 시작하기]를 두고, 누르면 홈(2-1)으로 간다.

#### Scenario: 아이 모드로
- **WHEN** 보호자가 [아이 모드 시작하기]를 누른다
- **THEN** 홈(2-1)이 보인다

### Requirement: 로그인과 로그아웃
The system SHALL 시작(1-1)의 [이미 계정이 있어요]는 로그인(1-0)으로 간다. 1-0의 [카카오로 로그인]과 [로그인]은 이 기기에 저장된 계정이 있으면 홈(2-1)으로 간다(이메일 로그인은 저장된 이메일과 같아야 한다). 설정의 로그아웃은 확인 창(5-9)을 띄우고, [로그아웃]이면 로그인 상태만 끈 채 시작(1-1)으로 가며, 아이 기록은 지우지 않는다. [취소]나 창 바깥은 설정으로 돌아간다.

#### Scenario: 로그아웃 후 다시 로그인
- **GIVEN** 저금통 카드가 있는 상태에서 로그아웃했다
- **WHEN** 1-1 → [이미 계정이 있어요] → 1-0에서 같은 이메일로 [로그인]을 누른다
- **THEN** 홈(2-1)이 보이고 지구 사전에 저금통 카드가 그대로 있다

#### Scenario: 저장된 계정이 없음
- **GIVEN** 이 기기에 계정 기록이 없다
- **WHEN** 1-0에서 [로그인]을 누른다
- **THEN** 홈으로 가지 않는다

### Requirement: 보호자 모드 잠금
The system SHALL 보호자 모드는 보호자 비밀번호 입력(5-1)을 거쳐야 열린다. 맞는 4자리를 누르면 보호자 홈(5-2)으로, 틀리면 비밀번호가 틀렸어요(5-1a)로 바뀌어 다시 받는다. "비밀번호를 잊으셨나요?"는 재설정(5-1b)으로 가고, [재설정 링크 보내기]는 실제로 메일을 보내지 않고 5-1로 돌아간다. 5-1의 "×"는 내 정보(3-4)로 간다. 잠금을 풀지 않고 보호자 화면 주소로 바로 들어오면 5-1을 보여준다.

#### Scenario: 맞는 번호
- **WHEN** 보호자가 5-1에서 저장한 4자리를 누른다
- **THEN** 보호자 홈(5-2)이 보인다

#### Scenario: 틀린 번호
- **WHEN** 5-1에서 다른 4자리를 누른다
- **THEN** "비밀번호가 맞지 않아요. 다시 입력해 주세요."가 보이고 입력칸이 비워진다

#### Scenario: 주소로 바로 들어옴
- **GIVEN** 보호자 잠금을 풀지 않았다
- **WHEN** 보호자 홈 주소를 직접 연다
- **THEN** 보호자 비밀번호 입력(5-1)이 보인다

### Requirement: 보호자 홈
The system SHALL 보호자 홈(5-2)에 "○○ 보호자님"과 아이 프로필 요약, 설정 버튼(→ 5-4), 이번 주 물어본 말 카드(베타 표시, 숫자 3개, "주간 리포트 보기"), 모야가 못 찾은 말 카드(→ 5-3), 무료 체험 질문 카드(베타 표시, "구독 알아보기"), [아이 모드로 돌아가기](→ 2-1, 보호자 잠금 다시 걸림)를 둔다. 베타 표시 항목(주간 리포트 보기, 구독 알아보기)은 눌러도 이동하지 않는다.

#### Scenario: 못 찾은 말로
- **GIVEN** 물어볼 단어 '저구멍'이 있다
- **WHEN** 보호자가 5-2의 모야가 못 찾은 말 카드를 누른다
- **THEN** 물어볼 단어(5-3)에 '저구멍'이 보인다

#### Scenario: 아이 모드로 돌아가기
- **WHEN** 보호자가 [아이 모드로 돌아가기]를 누른다
- **THEN** 홈(2-1)이 보이고, 다시 보호자 모드에 들어가려면 5-1을 거친다

### Requirement: 설정
The system SHALL 설정(5-4)에 아이 프로필(→ 5-5), 서비스 개선에 목소리 활용(선택) 토글, 음성 기록 삭제 요청(→ 5-7), 음성 수집 동의 철회(→ 5-8), 보호자 비밀번호 변경(→ 5-6), 구독 관리(베타 표시, 이동 없음), 주간 리포트 알림 토글, 로그아웃(→ 5-9)을 둔다. 토글은 누를 때마다 켜짐·꺼짐이 바뀌고 이 기기에 저장된다. 비밀번호 변경(5-6)은 새 4자리를 받아 지금 비밀번호와 다르면 저장하고 설정으로 돌아간다. "<"는 보호자 홈(5-2)으로 간다.

#### Scenario: 토글 저장
- **WHEN** 보호자가 주간 리포트 알림 토글을 끄고 설정을 다시 연다
- **THEN** 토글이 꺼진 채로 보인다

#### Scenario: 비밀번호 변경
- **WHEN** 보호자가 5-6에서 지금과 다른 4자리를 누른다
- **THEN** 설정(5-4)이 보이고, 다음 보호자 잠금에서는 새 번호로 열린다
