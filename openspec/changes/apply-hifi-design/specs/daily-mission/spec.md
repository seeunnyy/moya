# Spec Delta

## Purpose

아이가 모르는 말을 꾸준히 묻도록 별, 오늘의 미션(모르는 말 3개 물어보기), 로켓 도장을 주고, 아이 화면 헤더와 내 정보·내 별과 로켓 화면에서 보여준다. 모든 기록은 이 기기에만 저장한다.

## ADDED Requirements

### Requirement: 헤더의 미션 별과 별 개수
The system SHALL 아이 화면 헤더에 아바타, 오늘의 미션 별 3칸(오늘 모은 카드 수만큼 채움), 별 개수 칩을 보여준다. 아바타나 미션 별 3칸을 누르면 오늘의 미션 시트(2-0)를, 별 개수 칩을 누르면 내 별과 로켓(3-5)을 연다.

#### Scenario: 카드를 모으면 칸이 참
- **GIVEN** 오늘 모은 카드가 1장이고 별이 24개다
- **WHEN** 아이가 새 카드를 하나 더 모은다
- **THEN** 헤더 미션 별 2칸이 채워지고 별 개수가 25가 된다

#### Scenario: 별 개수 누르기
- **WHEN** 아이가 헤더의 별 개수 칩을 누른다
- **THEN** 내 별과 로켓(3-5)이 보인다

### Requirement: 오늘의 미션 시트
The system SHALL 오늘의 미션 시트(2-0)를 지금 화면 위에 띄워 "오늘의 미션", 오늘 날짜, "모르는 말 3개 물어보기"와 진행 별 3칸, "다 하면 별 +3 · 로켓 도장 +1", [지금 물어볼래](→ 듣는 중 2-2), [닫기]를 보여준다. [닫기]나 시트 바깥을 누르면 시트만 닫는다. 미션 진행은 날짜가 바뀌면 0으로 돌아간다.

#### Scenario: 시트에서 바로 묻기
- **WHEN** 아이가 2-0에서 [지금 물어볼래]를 누른다
- **THEN** 시트가 닫히고 듣는 중(2-2)이 되어 녹음이 시작된다

#### Scenario: 다음 날
- **GIVEN** 어제 미션 별 2칸을 채웠다
- **WHEN** 오늘 앱을 연다
- **THEN** 헤더 미션 별이 모두 비어 있다

### Requirement: 별 주기
The system SHALL 새 단어 카드를 모으면 별 1개, 오늘의 단어를 지구 사전에 넣으면 별 1개, 오늘의 미션을 성공하면 별 3개와 로켓 도장 1개를 주고, 별을 받을 때마다 이유와 날짜를 별 받은 기록에 남긴다. "모야에게 설명하기"(+2)는 베타라 주지 않는다.

#### Scenario: 별 받은 기록
- **WHEN** 아이가 저금통 카드를 새로 모은다
- **THEN** 내 별과 로켓(3-5)의 별 받은 기록 맨 위에 "저금통 카드 모았어 · 오늘 · +1"이 보인다

### Requirement: 오늘의 미션 성공
The system SHALL 오늘 물어서 모은 새 카드가 3장이 되는 순간의 카드 획득 화면(2-13)은 말풍선을 "○○ 카드 모았다! 오늘의 미션 끝!"으로 보이고, 1.5초 뒤 미션 성공 창(2-14: "오늘의 미션 성공!", "모르는 말 3개를 물어봤어", "별 +3", "로켓 도장 +1", [좋아!])을 띄운다. [좋아!]는 내 별과 로켓(3-5)으로 간다. 하루에 한 번만 성공 보상을 준다. 오늘의 단어로 넣은 카드는 미션에 세지 않는다.

#### Scenario: 세 번째 카드
- **GIVEN** 오늘 물어서 모은 카드가 2장이고 별이 25개다
- **WHEN** 아이가 우산 카드를 새로 모은다
- **THEN** 2-13이 보이고 1.5초 뒤 2-14가 뜬다
- **AND** 별 개수가 29가 되고 오늘 요일에 로켓 도장이 찍힌다

#### Scenario: 네 번째 카드
- **GIVEN** 오늘 미션을 이미 성공했다
- **WHEN** 아이가 새 카드를 또 모은다
- **THEN** 미션 성공 창은 뜨지 않고 별 1개만 받는다

### Requirement: 내 정보
The system SHALL 내 정보(3-4)에 아바타, 별명, "만 ○세 · 모야랑 ○일째", 모은 별·연속 학습(로켓 도장 연속 일수)·지구 사전 카드 수, 이번 주 로켓 도장(월~일, 오늘 표시), 보호자 메뉴(→ 5-1)를 보여준다. 모은 별과 연속 학습을 누르면 내 별과 로켓(3-5)으로, 지구 사전 카드 수를 누르면 지구 사전(3-1)으로 간다.

#### Scenario: 보호자 메뉴
- **WHEN** 아이가 내 정보에서 보호자 메뉴를 누른다
- **THEN** 보호자 비밀번호 입력(5-1)이 보인다

### Requirement: 내 별과 로켓
The system SHALL 내 별과 로켓(3-5)에 "<"와 제목, 모은 별 개수와 연속 로켓 도장 일수, 별 받은 기록(최근 것부터: 이유, 오늘·어제·날짜, +개수), "별은 이렇게 모아요" 안내를 보여준다. "<"는 이전 화면으로 간다.

#### Scenario: 이전 화면으로
- **GIVEN** 미션 성공 창에서 [좋아!]로 3-5에 왔다
- **WHEN** "<"를 누른다
- **THEN** 이전 화면이 보인다
