# Spec Delta

## MODIFIED Requirements

### Requirement: 홈에서 음성 녹음 화면으로
The system SHALL 홈(2-1, 모야와 놀기)에 헤더, 모야 말풍선("궁금한 점이 생겼어? 나랑 함께 알아보자!" + 스피커), 모야, 오늘의 단어 선물, 마이크 버튼("눌러서 말하기"), 하단 탭을 둔다. 마이크 권한이 허용돼 있으면 마이크를 누르는 즉시 같은 자리에서 듣는 중(2-2)이 된다. 권한을 아직 묻지 않았으면 브라우저 권한 창을 먼저 띄우고, 거부되거나 마이크를 쓸 수 없으면 마이크가 꺼져 있어요(E-2)로 간다. 필수 음성 동의가 꺼져 있으면 음성 수집 동의(1-4)로 보낸다. (FR-01)

#### Scenario: 홈에서 바로 녹음 화면
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 아이가 홈의 마이크를 누른다
- **THEN** 듣는 중(2-2) "응응, 듣고 있어!"가 보이고 녹음이 시작된다

#### Scenario: 권한을 아직 묻지 않음
- **GIVEN** 이 기기에서 마이크 권한을 아직 묻지 않았다
- **WHEN** 아이가 홈의 마이크를 누른다
- **THEN** 브라우저의 마이크 권한 창이 뜬다

### Requirement: 마이크 권한 안내
The system SHALL 온보딩의 마이크 권한 안내(1-6)에 단계 표시(5/5), 모야 말풍선("모야가 네 목소리를 들으려면 마이크가 필요해!" + 스피커), 모야, "다음 창에서 '허용'을 눌러 주세요" 안내, [마이크 켜기], [나중에 할게요]를 둔다. [마이크 켜기]는 브라우저의 실제 마이크 권한 창(1-7)을 띄우며 가짜 권한 창을 그리지 않는다. 허용되면 아이 모드 시작(1-8), 거부되면 마이크가 꺼져 있어요(E-2)로 간다. [나중에 할게요]는 1-8로 간다. "<"는 이전 단계로 간다. (FR-01, FR-13)

#### Scenario: 권한 허용
- **WHEN** 보호자가 [마이크 켜기]를 누르고 브라우저 창에서 허용한다
- **THEN** 아이 모드 시작(1-8) "준비 끝!"이 보인다

#### Scenario: 권한 거부
- **WHEN** 보호자가 [마이크 켜기]를 누르고 브라우저 창에서 허용하지 않는다
- **THEN** 마이크가 꺼져 있어요(E-2)가 보인다

#### Scenario: 나중에
- **WHEN** 보호자가 [나중에 할게요]를 누른다
- **THEN** 아이 모드 시작(1-8)이 보이고 권한 창은 뜨지 않는다

### Requirement: 마이크로 질문 녹음과 인식
The system SHALL 듣는 중(2-2)에 모야 말풍선 "응응, 듣고 있어!", 소리 표시, 녹음 중 마이크 버튼("듣고 있어…")을 보이고, 아이가 마이크를 다시 누르거나 최대 녹음 시간이 지나면 녹음을 멈추고 생각 중(2-3: "음… 무슨 말인지 찾아볼게!", 비활성 마이크 "모야가 찾고 있어")으로 간다. 생각 중에는 음성인식 결과(인식 후보 1개 이상)를 대상 단어 추출로 넘기고, 결과에 따라 확인 질문(2-4), 물어볼 단어(2-8), 다시 말해줄래(2-7), 부적절 단어 안내, 연결이 끊겼어요(E-1)로 간다. 생각 중의 마이크는 눌러도 반응하지 않는다. (FR-01)

#### Scenario: 질문이 인식됨
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 아이가 마이크를 누르고 "저금통이 뭐야?"라고 말한 뒤 마이크를 다시 누른다
- **THEN** 듣는 중(2-2) → 생각 중(2-3)을 거쳐 저금통 확인 질문(2-4)이 보인다

#### Scenario: 인식 후보가 여러 개
- **GIVEN** 음성인식이 인식 후보를 2개 이상 돌려준다
- **WHEN** 인식이 끝난다
- **THEN** 모든 인식 후보가 대상 단어 추출로 넘어간다

#### Scenario: 최대 녹음 시간
- **WHEN** 녹음을 시작하고 마이크를 다시 누르지 않는다
- **THEN** 최대 녹음 시간이 지나면 녹음을 멈추고 생각 중(2-3)으로 간다

#### Scenario: 권한을 아직 묻지 않음
- **GIVEN** 이 기기에서 마이크 권한을 아직 묻지 않았다
- **WHEN** 아이가 카드 획득(2-10)에서 [또 물어볼래]를 누른다
- **THEN** 브라우저의 마이크 권한 창이 먼저 뜨고, 허용하면 듣는 중(2-2)이 된다

#### Scenario: 다시 말하기 링크
- **WHEN** 듣는 중(2-2)과 생각 중(2-3) 화면을 확인한다
- **THEN** 옛 링크 "다시 말하기"는 없고, 듣는 중에는 마이크를 다시 눌러 녹음을 끝낸다

#### Scenario: 녹음 중 화면을 떠남
- **WHEN** 녹음 중에 아이가 하단 탭으로 다른 화면에 간다
- **THEN** 녹음을 멈추고 마이크를 닫으며, 녹음한 내용은 보내지 않는다

### Requirement: 다시 말하기 안내
The system SHALL 음성인식 결과가 비어 있거나 대상 단어를 꺼내지 못하면 못 알아들은 흐름의 듣는 중·생각 중(2-11, 2-12)과 같은 모습을 거쳐 다시 말해줄래(2-7)를 보여준다: 모야 말풍선 "앗, 잘 못 들었어. 한 번만 더 말해줄래?", 모야, 마이크("다시 말하기"), [글자 카드로 고를래]. 마이크는 듣는 중(2-2)으로, [글자 카드로 고를래]는 후보 고르기(2-6)로 간다. 고를 후보가 없으면 [글자 카드로 고를래]는 글자 입력·예시 버튼 폴백을 보여준다. (NFR-07)

#### Scenario: 질문 형태가 아님
- **WHEN** 인식 텍스트가 "저금통"(질문 아님)이다
- **THEN** 다시 말해줄래(2-7)가 보인다
- **AND** 마이크를 누르면 듣는 중(2-2)이 된다

#### Scenario: 네트워크 오류
- **GIVEN** 네트워크가 끊겨 있다
- **WHEN** 아이가 질문을 녹음한다
- **THEN** 다시 말해줄래(2-7)가 아니라 연결이 끊겼어요(E-1)가 보인다("연결이 끊겼을 때")

### Requirement: 마이크를 쓸 수 없을 때
The system SHALL 마이크를 쓸 수 없으면(권한 거부, 마이크 없음, 브라우저 미지원, http 접속) 마이크가 꺼져 있어요(E-2)를 보여준다: 모야 말풍선 "마이크가 꺼져 있어서 네 목소리가 안 들려!", 보호자용 켜는 방법 안내, [다시 해 볼래](→ 브라우저 권한 다시 요청, 1-7), [보호자에게 도움 요청](→ 5-1). 시연 안정성을 위해 마이크를 쓸 수 없는 동안에는 홈(2-1)과 E-2에서 글자 입력과 서툰 발음 예시 버튼을 함께 보여주고, 마이크를 쓸 수 있으면 숨긴다(피그마에 없는 부분, 배치는 design.md). (FR-13, NFR-07)

#### Scenario: 권한 거부 후 텍스트로 계속
- **GIVEN** 마이크 권한이 거부돼 있다
- **WHEN** 아이가 홈의 마이크를 누른다
- **THEN** 마이크가 꺼져 있어요(E-2)와 글자 입력·예시 버튼이 보인다
- **AND** 글자로 "저금통이 뭐야?"를 입력하면 마이크로 물은 것과 같은 흐름으로 진행된다

#### Scenario: 평소에는 숨김
- **GIVEN** 마이크 권한이 허용돼 있다
- **WHEN** 홈(2-1)이 열린다
- **THEN** 글자 입력과 예시 버튼이 보이지 않는다

### Requirement: 서툰 발음 예시 버튼
The system SHALL 폴백 상태의 예시 버튼을 누르면 그 문장을 인식 텍스트로 삼아 생각 중(2-3)부터 같은 흐름을 진행한다. 예시 문장은 피그마 시연 단어(저금통 흐름 등)에 맞춘 mock 데이터에서 가져온다. (FR-13)

#### Scenario: 마이크 없이 되묻기 재현
- **GIVEN** 폴백 상태다
- **WHEN** 아이가 서툰 발음 예시 버튼을 누른다
- **THEN** 마이크를 쓰지 않고 확인 질문(2-4)까지 진행할 수 있다

### Requirement: 대상 단어 추출
The system SHALL 인식 텍스트에서 "○○이 뭐야", "○○가 뭐야", "○○ 뭐야" 형태의 ○○을 대상 단어로 꺼낸다. 인식 후보가 여러 개면 각각에서 꺼낸다. 어느 후보에서도 꺼내지 못하면 다시 말해줄래(2-7)를 보여준다. (FR-02)

#### Scenario: 조사 '이'가 붙은 질문
- **WHEN** 인식 텍스트가 "공룡이 뭐야?"이다
- **THEN** 대상 단어는 "공룡"이다

#### Scenario: 조사 '가'가 붙은 질문
- **WHEN** 인식 텍스트가 "가바가 뭐야"이다
- **THEN** 대상 단어는 "가바"이다

#### Scenario: 질문 형태가 아님
- **WHEN** 인식 텍스트가 "공룡"이거나 비어 있다
- **THEN** 다시 말해줄래(2-7)가 보인다

## ADDED Requirements

### Requirement: 연결이 끊겼을 때
The system SHALL 음성인식 요청이 네트워크 오류로 실패하면 자동으로 한 번 다시 시도하고, 그래도 실패하면 연결이 끊겼어요(E-1)를 보여준다: 모야 말풍선 "앗, 모야 우주선 신호가 약해! 다시 해 볼까?", 모야, "자동으로 한 번 다시 시도했어요", [다시 해 볼래](→ 듣는 중 2-2), [처음으로](→ 홈 2-1). (NFR-07)

#### Scenario: 네트워크 오류
- **GIVEN** 네트워크가 끊겨 있다
- **WHEN** 아이가 질문을 녹음한다
- **THEN** 한 번 다시 시도한 뒤 연결이 끊겼어요(E-1)가 보인다
- **AND** [처음으로]를 누르면 홈(2-1)이 보인다
