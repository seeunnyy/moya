# Spec Delta

## MODIFIED Requirements

### Requirement: 검수된 데이터로만 설명
The system SHALL 확정한 단어를 뜻 알려주기(2-9)와 카드 획득(2-10)으로 설명한다. 2-9에는 단어를 한 글자씩 나눈 글자 타일, 모야, 설명 말풍선(+ 스피커), [알았어!](→ 2-10)를 둔다. 2-10에는 말풍선 "○○ 카드 모았다! 별 1개 받았어!", 카드(새 카드 표시와 날짜, 그림, 단어, '내가 말한 소리' 칩, 쉬운 설명, "예)"로 시작하는 예문, 복습 안내 줄), [또 물어볼래](→ 듣는 중 2-2), 지구 사전 버튼(→ 3-1)을 둔다. 설명·예문·힌트는 검수된 단어 데이터에서 그대로 가져오고, 실행 중에 새로 만들지 않으며, 데이터에 없는 단어는 설명하지 않는다. 복습 안내 줄은 베타라 보이기만 한다. 영어 표기는 새 피그마에 없어 화면에 보이지 않는다(데이터에는 남김). (FR-07, NFR-05)

#### Scenario: 설명 보여주기
- **GIVEN** 아이가 저금통을 확정했다
- **WHEN** 2-9가 열린다
- **THEN** 글자 타일 "저" "금" "통"과 단어 데이터의 2-9용 설명이 보인다

#### Scenario: 카드에 예문
- **GIVEN** 2-9에서 [알았어!]를 눌렀다
- **WHEN** 카드 획득(2-10)이 열린다
- **THEN** 단어 데이터의 쉬운 설명과 "예) …" 예문이 그대로 보인다

#### Scenario: 영어 표기가 없는 단어
- **GIVEN** 단어 데이터에 영어 표기가 있거나 없다
- **WHEN** 카드 획득(2-10)이 열린다
- **THEN** 어느 경우에도 영어 표기 줄이 보이지 않는다

#### Scenario: 또 물어보기
- **GIVEN** 2-10이 보인다
- **WHEN** 아이가 [또 물어볼래]를 누른다
- **THEN** 듣는 중(2-2)이 되고 녹음이 시작된다

### Requirement: 모야의 대사를 소리로 들려주기
The system SHALL 화면이 바뀌면 모야 말풍선의 대사를 기기 음성으로 읽어 준다. 모든 말풍선과 단어 카드에는 스피커 버튼이 있고, 누르면 그 대사(또는 단어와 설명·힌트)를 처음부터 다시 읽으며 읽는 동안 재생 중 표시를 한다. '내가 말한 소리' 칩의 스피커는 인식된 글자를 읽는다(녹음을 재생하지 않음). 기기가 음성 출력을 지원하지 않으면 글자만 보여주고 흐름을 계속한다. (FR-08)

#### Scenario: 대사 읽기
- **GIVEN** 음성 출력을 지원하는 기기다
- **WHEN** 확인 질문 화면(2-4)이 열린다
- **THEN** "저금통 말하는 거야?"가 소리로 나오고 보조기기 알림 영역에도 들어간다

#### Scenario: 다시 듣기
- **GIVEN** 2-9에 설명 말풍선이 보인다
- **WHEN** 아이가 말풍선의 스피커를 누른다
- **THEN** 설명을 처음부터 다시 읽고 재생 중 표시가 보인다

#### Scenario: 녹음 중에는 읽지 않음
- **GIVEN** 모야가 대사를 읽고 있다
- **WHEN** 아이가 마이크를 누른다
- **THEN** 읽던 대사를 멈추고, 듣는 중·생각 중에는 아무것도 읽지 않는다

#### Scenario: 음성 출력 미지원
- **GIVEN** 음성 출력을 지원하지 않는 기기다
- **WHEN** 모야의 대사가 나온다
- **THEN** 오류 없이 다음 단계로 진행할 수 있다
