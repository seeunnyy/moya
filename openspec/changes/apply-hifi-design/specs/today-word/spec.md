# Spec Delta

## Purpose

아이가 묻지 않아도 날마다 검수된 단어 하나를 모야가 소개하고, 아이가 원하면 지구 사전에 넣을 수 있게 한다.

## ADDED Requirements

### Requirement: 오늘의 단어 고르기
The system SHALL 날마다 검수된 단어 데이터 중 아직 지구 사전에 없는 단어 하나를 오늘의 단어로 정하고, 같은 날에는 같은 단어를 보여준다. 홈(2-1)의 선물 버튼("오늘의 단어")은 오늘의 단어를 아직 열어 보지 않았으면 빨간 점을 붙인다. 지구 사전에 없는 단어가 하나도 없으면 선물 버튼을 숨긴다.

#### Scenario: 같은 날 같은 단어
- **GIVEN** 오늘의 단어가 달팽이로 정해졌다
- **WHEN** 같은 날 오늘의 단어를 다시 연다
- **THEN** 달팽이가 보인다

#### Scenario: 빨간 점
- **GIVEN** 오늘의 단어를 아직 열지 않았다
- **WHEN** 홈(2-1)을 연다
- **THEN** 선물 버튼에 빨간 점이 보인다

### Requirement: 오늘의 단어 보기와 넣기
The system SHALL 오늘의 단어(3-3)에 헤더, 작은 모야와 말풍선 "오늘의 단어는 '○○'이야! 같이 알아볼까?" + 스피커, 단어 카드(그림, 단어, 쉬운 설명, 스피커), [지구 사전에 넣기], [내일 또 볼래](→ 2-1)를 둔다. [지구 사전에 넣기]를 누르면 그 단어 카드를 지구 사전에 넣고 별 1개를 준 뒤 카드 모았다 화면(3-3a: "○○ 카드 모았다! 지구 사전에 넣었어!", 카드, [지구 사전 보기](→ 3-1), [모야랑 놀기](→ 2-1))을 보여준다. 이미 넣은 날 다시 열면 3-3a를 보여준다.

#### Scenario: 지구 사전에 넣기
- **GIVEN** 오늘의 단어 달팽이가 보이고 별이 24개다
- **WHEN** 아이가 [지구 사전에 넣기]를 누른다
- **THEN** 3-3a "달팽이 카드 모았다! 지구 사전에 넣었어!"가 보이고 별이 25개가 된다
- **AND** 지구 사전에 달팽이 카드가 생기고 오늘의 미션 칸은 그대로다

#### Scenario: 내일 또 볼래
- **WHEN** 아이가 [내일 또 볼래]를 누른다
- **THEN** 홈(2-1)이 보이고 지구 사전에는 아무것도 추가되지 않는다
