# Spec Delta

## Purpose

아이가 욕설·성적·폭력적인 단어를 물었을 때 설명하거나 기록하지 않고, 보호자에게 묻도록 부드럽게 안내한다.

## ADDED Requirements

### Requirement: 부적절한 단어 안내
The system SHALL 대상 단어가 부적절 단어 목록에 있으면 후보 찾기·되묻기·설명을 하지 않고 부적절 단어 안내(E3: 다시 말하기 안내와 같은 레이아웃, "그 말은 엄마·아빠한테 물어보자!", [다시 녹음하기])를 보여준다. 이 단어는 단어 카드나 물어볼 단어로 저장하지 않는다. 부적절 단어 목록의 내용과 판별 기준은 별도로 정한다. (NFR-06)

#### Scenario: 목록에 있는 단어
- **GIVEN** 부적절 단어 목록에 어떤 단어가 있다
- **WHEN** 아이가 그 단어로 "○○이 뭐야?"라고 묻는다
- **THEN** "그 말은 엄마·아빠한테 물어보자!" 안내와 [다시 녹음하기]가 보이고, 저장 버튼은 없다
- **AND** 단어 카드 목록에 그 단어가 추가되지 않는다

#### Scenario: 목록에 없는 단어
- **WHEN** 아이가 "공룡이 뭐야?"라고 묻는다
- **THEN** 안내 없이 평소처럼 되묻기 단계로 진행된다
