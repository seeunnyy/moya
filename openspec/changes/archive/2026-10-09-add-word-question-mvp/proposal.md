# Proposal: 모야 MVP — 묻기 → 되묻기 → 단어 카드

## Why

글을 막 배우는 만 5~8세 아이는 철자를 몰라 들은 단어를 사전에서 찾을 수 없고, 기존 음성 AI는 아이 발음을 잘 못 알아듣는다(국내 5~7세 AI 스피커 대화 실패율 31.6%). 11/5 1차 배포와 11/6 사용성 테스트 전에, 아이가 서툴게 물어도 모야가 되물어 단어를 찾고 설명해 주는 핵심 시나리오를 끝까지 동작하게 만든다. (근거: planning/md-design/01_PRODUCT_BRIEF.md)

## What Changes

- 아이가 마이크로 "○○이 뭐야?"라고 물으면 인식 텍스트에서 대상 단어를 꺼낸다. 마이크를 못 쓰면 텍스트 입력이나 서툰 발음 예시 버튼으로 같은 흐름을 진행한다. (FR-01, FR-02, FR-13)
- 서툰 발음은 발음 역규칙과 자모 거리로 검수된 단어 데이터에서 후보를 찾는다. 인식에 성공하면 되묻기 화면에서 후보를 미리 보여주고, 후보 1개면 확인 질문, 여러 개면 후보 카드를 눌러 고르게 하고, 못 찾으면 물어볼 단어 안내로 간다. (FR-03~06)
- 고른 단어의 쉬운 설명과 영어 표기를 검수된 데이터에서 단어 카드로 보여주고 기기 음성으로 읽어 준다. 예문은 데이터에만 둔다. (FR-07, FR-08)
- 설명한 단어와 못 찾은 단어는 아이가 [내 단어장에 저장하기]를 누르면 각각 카드와 '물어볼 단어'로 이 기기에 저장하고, 단어 카드 목록(학습 상태 필터)과 카드 상세에서 본다. (FR-06, FR-09, FR-10)
- 화면 구성·버튼·이동·스타일은 Figma 와이어프레임(Section 1)과 똑같이 만든다(이동은 Figma 연결 → Manyfast '새 플로우 1' 순). 결정과 Figma와 다른 부분은 design.md "Figma 와이어프레임 전면 적용 (2차)".
- 무엇이 저장·전송되는지 보호자 화면(/parent)에 알리고, 부적절한 단어는 설명하지 않고 어른에게 묻도록 안내한다. (NFR-04, NFR-06, NFR-09)
- 390px 기준(375px에서도 넘침 없음) 모바일, 48px 이상 터치 영역, 키보드 조작, 대사 읽어 주기(aria-live)를 지킨다. (NFR-01, NFR-08)
- 범위 밖: 반복 학습(F4), 부모 리포트(F5), LLM 실시간 설명·재순위, 사전 API, 결제·로그인. 상세는 design.md Non-Goals.

## Capabilities

### New Capabilities
- `voice-question`: 아이 질문 입력(마이크, 텍스트, 예시 버튼)과 대상 단어 추출, 입력 실패 처리
- `word-inference`: 서툰 발음에서 의도한 단어 후보 찾기, 되묻기 화면, 확인 질문, 후보 카드로 고르기, 물어볼 단어로 넘기기
- `word-explanation`: 고른 단어의 쉬운 설명·영어 표기 보여주기와 음성으로 읽어 주기
- `word-cards`: 단어 카드와 물어볼 단어의 저장과 단어장 목록
- `content-safety`: 아이에게 부적절한 단어 처리
- `privacy-notice`: 음성·데이터 처리 방식 고지 (보호자 화면)
- `child-accessibility`: 아이 화면의 모바일·접근성 기준

## Impact

- 화면: `/app`(아이 모드 홈 S9), `/app/mic`(마이크 권한 안내 S10), `/app/ask`(S1, E1~E3, S12, S3~S6), `/app/cards`(S7), `/app/cards/[id]`(카드 상세 S11), `/`(S0 최소), `/parent`(S8 저장·전송 안내, 부모 리포트는 베타)
- 스타일: Figma 와이어프레임 값을 Tailwind `@theme` 토큰으로 정의, 폰트 Noto Sans KR(next/font/google, 새 패키지 없음)
- 서버: 음성인식 서버 라우트 1개 추가 (API 키는 서버 전용)
- 외부 의존: STT 서비스 1개 (선정 중, 처음엔 mock)
- 데이터: 검수된 단어 데이터와 발음 역규칙 표를 소스에 포함. 사용자 데이터는 브라우저 저장소에만 둔다
- 개발 환경: 단위 테스트는 Node 내장 테스트 러너로 실행 (새 패키지 없음)
