## 3. Interactions
- **마이크:** [녹음 시작]을 누르면 권한을 아직 묻지 않았을 때는 권한 안내(S10)로 가고, 허용돼 있으면 바로 녹음한다. 같은 화면에서 버튼이 [그만하기] → "생각 중…"으로 바뀐다. [그만하기]나 최대 녹음 시간(8초, 잠정)으로 끝낸다.
- **모야의 대사:** 화면이 바뀌면 대사를 소리로 읽고 aria-live 영역에 넣는다. 화면에는 따로 보이지 않는다.
- **되묻기(S12):** 인식에 성공하면 항상 거친다. 결과에 맞는 버튼 하나만 보인다. 미리보기 [들어보기]는 소리만 낸다.
- **후보 카드(S4):** 카드 자체를 누르면 확정. [들어보기]는 소리만 내고 선택하지 않는다. 눈에 보이는 고르기 버튼은 없다.
- **[아니에요] / [여기 없어요]:** 다시 말하기 기회를 1번 준다(S1). 그래도 아니면 물어볼 단어 안내(S6)로 간다.
- **저장:** S5·S6의 [내 단어장에 저장하기]를 눌러야 저장한다. 결과는 버튼 글자로만 보여준다(S5 "저장했어!", S6 "적어 뒀어!", 실패 "다시 저장하기"). 누르지 않고 떠나면 저장하지 않는다.
- **"<":** 음성 녹음·물어볼 단어 안내·보호자 → 홈, 카드 상세 → 목록, 그 밖 → 이전 화면.
- **저장·전송 고지:** 보호자 화면(S8)에 둔다. 문구 (잠정): "목소리는 글자로 바꾸는 데만 쓰고 저장하지 않아요. 물어본 단어는 이 기기에만 저장돼요."
- **폴백:** 마이크를 쓸 수 없으면 S1의 [녹음 시작] 아래에 텍스트 입력과 예시 버튼이 보인다. 예시 버튼은 서툰 발음 문장으로 되묻기 장면을 그대로 보여준다(05 §5).
- **화면 전환:** 화면은 자동으로 넘어가지 않는다. 시간 제한도 없다.

## 4. Accessibility
- 버튼에는 짧고 쉬운 글자를 쓴다. 와이어프레임 단계 예외: 헤더 "<"는 글자 없이 aria-label("이전 화면"/"홈으로")만 단다. 디자인 단계에서 다시 본다.
- 보이는 크기는 Figma 그대로(버튼 33~35px, 링크 17px) 두고, 누르는 영역은 투명하게 최소 48×48px로 넓힌다.
- 텍스트 대비는 WCAG AA(4.5:1) 이상으로 하고, 색만으로 상태를 구분하지 않는다.
- 모야의 대사는 화면에 보이지 않는 `aria-live` 영역에 넣고, 화면마다 본문 제목을 h1로 둔다(헤더 화면 이름은 h1이 아님).
- 키보드로 모든 버튼을 조작할 수 있고, 포커스가 보인다.
- `prefers-reduced-motion`이면 캐릭터 애니메이션을 줄인다. 1초에 3번 넘게 깜빡이는 효과는 쓰지 않는다.
- 아이 화면의 문장은 짧고 쉬운 말로 쓴다.
