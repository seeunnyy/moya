## 3. Acceptance Criteria (MVP)
GIVEN/WHEN/THEN 원본은 openspec 델타 스펙(voice-question, word-inference, word-explanation, word-cards, daily-mission, today-word, guardian-account, parent-word-teaching, privacy-notice, content-safety, child-accessibility). 여기에는 상태 기계·저장 테스트로 지키는 핵심만 둔다(그룹 3).

**FR-01·02 녹음·인식·추출**
- Given 2-1, When 마이크 → 다시 누름, Then 2-2 → 2-3을 거쳐 인식 결과로 간다. 2-3에서 마이크는 반응하지 않는다.
- Given 인식 텍스트가 "저금통"(질문 아님)이거나 비어 있을 때, Then 2-7.

**FR-03 후보**
- "두박" → 수박 거리 0, "저그통" → 저금통 거리 1, 4개 이상이면 가까운 3개, 여러 대상 단어는 합치고 같은 단어는 가장 가까운 거리 하나.
- 인식 후보 "저굼통·저욷·조굼" → 저금통·저울·조금(모두 거리 1, 데이터 순), 각 카드의 '내가 말한 소리'는 저굼통·저욷·조굼.
- 보호자가 "저구멍"에 저금통을 알려 줬으면 "저구멍" → 저금통이 첫 후보(들은 곳 정렬보다 앞).

**FR-04·05 확인 질문·들은 곳·후보 고르기**
- 2-4 [맞아!] → 첫 후보의 2-9. [아니야] → 2-5.
- 2-5 [밖에서] → 2-6에서 같은 거리 후보 중 '밖에서' 태그 단어가 앞. [잘 모르겠어] → 순서 그대로. 2-4의 단어도 2-6에 남는다.
- 2-6 카드 → 그 단어의 2-9, [다 아니야] → 2-8.

**FR-06 물어볼 단어**
- "저구멍이 뭐야?" → 2-8, 말한 소리 "저구멍". [알았어!] → 2-1, [다른 말 물어볼래] → 2-2.

**FR-09 카드 자동 획득**
- 지구 사전에 없는 단어면 카드 저장·별 +1·미션 +1. 이미 있으면 카드·별·미션 그대로, 있던 카드를 보여준다.
- 저장소 쓰기가 실패해도 화면은 깨지지 않는다.

**FR-13 폴백·예외**
- E-2(micOff)와 2-1, 2-7 폴백에서 글자 "저굼통이 뭐야?" → 2-4 저금통.
- 네트워크 오류 → 한 번 다시 시도 → 실패면 E-1. [다시 해 볼래] → 2-2, [처음으로] → 2-1. 서버 실패 응답·빈 결과는 다시 시도하지 않고 2-7.
- 부적절 단어 → 안내, 후보 찾기·저장·별 없음.

**FR-14·15 계정·잠금**
- 계정이 없는 기기에서 /, /app, /parent/* → 1-1. 계정이 있으면 / → 2-1.
- 잠금을 풀지 않고 /parent/home·/parent/words·/parent/settings(/*) → 5-1. 잠금을 푼 뒤 보호자 주소 안에서는 유지, 새로고침·[아이 모드로 돌아가기] 뒤에는 다시 5-1.

**FR-16 별·미션·로켓**
- 오늘 2장·별 25에서 새 카드 → 2-13, 1.5초 뒤 2-14, 별 29, 오늘 도장. 네 번째 새 카드는 별 1개만.
- 자정이 지나면 헤더 미션 별이 0. 연속 학습은 오늘(또는 어제)까지 이어진 도장 일수, 하루 끊기면 0.

**FR-17 오늘의 단어**
- 같은 날 같은 단어, 지구 사전에 있는 단어는 고르지 않음, 모두 모았으면 선물 숨김. 넣으면 별 +1, 미션 칸 그대로.

**NFR-10 저장**
- 옛 카드(`status` 없음, 들은 곳 "adult")는 그대로 읽히고 옛 들은 곳만 버린다. 새 키는 없거나 손상되면 기본값, 쓰기 실패는 false.
