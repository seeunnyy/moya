## 1. Functional Requirements
| ID | 기능 | 요구사항 | 단계 |
|---|---|---|---|
| FR-01 | F1 | 마이크 버튼으로 아이의 질문을 녹음하고 텍스트로 인식한다. STT가 인식 후보를 여러 개 주면 모두 다음 단계로 넘긴다. | MVP |
| FR-02 | F1 | 인식 텍스트에서 대상 단어를 추출한다. ("○○이 뭐야", "○○가 뭐야", "○○ 뭐야" 등) | MVP |
| FR-03 | F2 | 대상 단어를 자모 분해 → 발음 역규칙 적용 → 검수된 단어 데이터와 거리 비교해 후보를 만든다. 인식 후보가 여러 개면 각각에서 대상 단어를 추출해 모두 비교한다. | MVP |
| FR-04 | F2 | 후보가 1개면 고정 문장 틀(2~3종)에 단어별 힌트를 붙여 확인 질문을 한다. (예: "저금통 말하는 거야? 돈을 모아 두는 통!") | MVP |
| FR-05 | F2 | 후보가 여러 개면 "어디서 들었어?"라고 맥락 질문을 하고, 아이는 상황 버튼(TV / 책 / 어른 말 / 유치원·학교 / 모르겠어, 잠정) 중 하나를 고른다. 고른 상황을 들은 상황으로 기록하고, 거리가 같은 후보 중 그 상황 태그를 가진 단어를 앞에 둔다. 후보 2~3개를 힌트와 함께 보여주고 아이가 고르게 한다. LLM 재순위는 베타다. | MVP |
| FR-06 | F2 | 후보가 0개이거나 아이가 모두 아니라고 하면 '물어볼 단어'로 저장한다. | MVP |
| FR-07 | F3 | 고른 단어의 쉬운 설명(한두 문장)과 일상 예문 1개를 검수된 단어 데이터에서 보여준다. 들은 상황이 있으면 함께 보여준다 (잠정). 사전 뜻 범위를 벗어난 내용은 데이터에 넣지 않는다. | MVP |
| FR-08 | F3 | 모야의 대사와 설명을 브라우저 내장 음성합성으로 들려준다. | MVP |
| FR-09 | F3 | 아이가 [내 단어장에 저장하기]를 누르면 단어 카드(단어, 사전 뜻, 쉬운 설명, 예문, 들은 상황, 처음 말한 발음, 날짜)를 저장한다. | MVP |
| FR-10 | F3 | 저장한 단어 카드와 '물어볼 단어'를 목록으로 보고, 카드를 눌러 상세를 본다. | MVP |
| FR-11 | F4 | 1·3·7일 뒤 모야가 단어를 다시 묻고, 아이 설명을 사전 뜻과 비교해 칭찬·보충한다. | 베타 |
| FR-12 | F5 | 주간 학습 기록과 물어볼 단어를 부모 화면에 정리한다. | 베타 |
| FR-13 | F1 | 마이크 권한이 거부되거나 인식에 실패하면 텍스트 입력과 예시 단어로 계속할 수 있다. 예시 단어 버튼은 서툰 발음 문장(예: [두박이 뭐야?])을 입력해, 마이크 없이도 되묻기 장면을 재현한다. | MVP |

## 2. Non-Functional Requirements
| ID | 요구사항 |
|---|---|
| NFR-01 | 모바일 세로(375px) 기준으로, 모바일 Chrome과 Safari에서 동작한다. |
| NFR-02 | 질문이 끝나고 모야의 첫 반응까지 3초 이내 (잠정, API 연동 후 측정해 확정). 기다리는 동안 '생각 중' 상태를 보여준다. |
| NFR-03 | 외부 API 키는 서버 전용(.env.local)으로 두고, 클라이언트에 노출하지 않는다. |
| NFR-04 | 음성 원본은 저장하지 않고 인식 텍스트만 저장한다. 아이 음성은 인식을 위해 외부 STT로 전송되므로, 데이터를 보관하지 않거나 보관 기간이 명시된 STT를 고른다. 사용성 테스트(11/6) 전에 보호자 동의서를 확정한다 (녹음 테스트 양식 재사용). |
| NFR-05 | 단어 데이터에 없는 단어는 설명을 만들지 않는다. |
| NFR-06 | 욕설·성인용·폭력적인 단어를 물으면 설명하지 않고, "엄마·아빠한테 물어보자"로 안내한다. (판별 기준 TBD) |
| NFR-07 | 마이크 권한 거부·인식 실패 시 다시 말하기 경로를 준다. |
| NFR-08 | 접근성은 03_UX_UI_SPEC.md §4 규칙을 따른다. |
| NFR-09 | 무엇이 저장되고 어디로 전송되는지(음성은 글자로 바꾸는 데만 쓰고 저장 안 함, 인식 텍스트만 이 기기에 저장)를 화면에서 확인할 수 있다. |

## 3. Acceptance Criteria (MVP)
**FR-01 음성 녹음·인식**
- Given S1에서 마이크 권한이 허용돼 있을 때, When 마이크 버튼을 누르고 말하면, Then 녹음이 끝난 뒤 인식 텍스트로 다음 단계(FR-02)를 진행한다.
- Given 녹음 중일 때, When [그만하기]를 누르면, Then 녹음을 멈추고 S1로 돌아간다.
- Given 음성인식 요청이 실패했을 때, When 오류 응답을 받으면, Then E2를 보여준다.
- Given STT가 인식 후보를 여러 개 돌려줬을 때, When 인식이 끝나면, Then 모든 후보 텍스트를 FR-02로 넘긴다.

**FR-02 대상 단어 추출**
- Given 인식 텍스트가 "공룡이 뭐야?"일 때, When 단어를 추출하면, Then 대상 단어는 "공룡"이다.
- Given "○○ 뭐야" 패턴이 없거나 텍스트가 비어 있을 때, When 추출에 실패하면, Then E2 "다시 말해줄래?"를 보여준다.

**FR-03 후보 생성**
- Given 단어 데이터에 "수박"이 있을 때, When 입력이 "두박"이면, Then 역규칙(ㄷ→ㅅ) 변형으로 "수박"이 거리 0의 후보가 된다.
- Given 입력과 거리 2 이하인 단어가 없을 때, When 후보를 만들면, Then 결과는 `unknown`이다.
- Given 거리 2 이하인 단어가 4개 이상일 때, When 후보를 만들면, Then 거리순 상위 3개만 남긴다.
- Given 인식 후보가 "두박이 뭐야", "두부가 뭐야" 두 개일 때, When 후보를 만들면, Then 두 대상 단어 각각의 결과를 합치고 같은 단어는 더 가까운 거리 하나만 남긴다.

**FR-04 확인 질문**
- Given 후보가 1개일 때, When S3이 열리면, Then 문장 틀과 그 단어의 힌트를 글자로 보여준다.
- Given S3에서, When 아이가 [응]을 고르면, Then S5 설명으로 넘어간다.
- Given S3에서 다시 말하기를 아직 쓰지 않았을 때, When [아니야]를 고르면, Then S1로 돌아가 한 번 더 말하게 한다. 다시 말하기를 이미 썼다면 FR-06으로 간다.

**FR-05 맥락 질문과 후보 고르기**
- Given 후보가 2~3개일 때, When S4가 열리면, Then "어디서 들었어?"와 상황 버튼을 먼저 보여준다.
- Given 가방(태그: 유치원·학교)과 가발(태그: TV)이 둘 다 거리 1일 때, When 아이가 [TV]를 고르면, Then 가발 카드가 첫 번째로 나온다.
- Given 상황 버튼이 보일 때, When 아이가 [모르겠어]를 고르면, Then 거리순으로 후보 카드를 보여주고 들은 상황은 비워 둔다.
- Given 후보 카드가 보일 때, When 카드를 누르고 [이거야!]를 고르면, Then 그 단어로 S5에 가고 고른 상황을 `heardContext`로 넘긴다.
- Given S4에서, When [다 아니야]를 고르면, Then FR-04와 같은 다시 말하기 규칙을 따른다.

**FR-06 물어볼 단어**
- Given 후보가 0개일 때, When 결과가 나오면, Then S6을 보여주고 인식 텍스트를 물어볼 단어로 저장한다.
- Given 다시 말하기를 쓴 뒤에도 [아니야]나 [다 아니야]를 골랐을 때, When 선택하면, Then S6으로 가서 물어볼 단어로 저장한다.

**FR-07 설명**
- Given 단어를 골랐을 때, When S5가 열리면, Then 그 단어 데이터의 쉬운 설명과 예문을 보여준다.
- Given 맥락 질문의 답이 있을 때, When S5가 열리면, Then 들은 상황을 함께 보여준다 (잠정).

**FR-08 음성 출력**
- Given 모야의 대사가 화면에 나올 때, When 대사가 바뀌면, Then 같은 문장을 음성으로 읽는다.
- Given 기기가 speechSynthesis를 지원하지 않을 때, When 대사가 나오면, Then 글자만 보여주고 오류 없이 진행한다.

**FR-09 카드 저장**
- Given S5 단어 카드가 보일 때, When [내 단어장에 저장하기]를 누르면, Then FR-09의 필드를 가진 카드가 저장되고 버튼이 "저장했어!"로 바뀌어 비활성이 된다.
- Given S5 단어 카드가 보일 때, When 저장 버튼을 누르지 않고 화면을 떠나면, Then 카드는 저장되지 않는다. (물어볼 단어는 S6에서 자동 저장)
- Given 저장소 쓰기가 실패했을 때, When 저장을 시도하면, Then 화면이 깨지지 않고 "저장하지 못했어" 안내를 보이며 흐름을 계속 진행한다.

**FR-10 단어장**
- Given 카드가 저장돼 있을 때, When S7을 열면, Then 단어 카드와 물어볼 단어가 목록으로 보이고, 새로고침해도 남아 있다.
- Given 저장된 것이 없을 때, When S7을 열면, Then 빈 상태 안내를 보여준다.
- Given 카드가 저장돼 있을 때, When S7에서 카드를 누르면, Then 카드 상세(S11, /app/cards/[id])가 보인다. 없는 id면 안내와 [단어 카드 목록으로]를 보여준다.

**FR-13 폴백**
- Given 마이크 권한이 거부됐을 때, When S1에서 마이크를 누르면, Then E1을 보여주고 텍스트 입력과 예시 단어로 계속할 수 있게 한다.
- Given 텍스트 입력이나 예시 단어를 썼을 때, When 제출하면, Then FR-02부터 같은 흐름으로 진행한다.
- Given 예시 단어 버튼 [두박이 뭐야?]가 보일 때, When 누르면, Then 마이크 없이 S3 "수박 말하는 거야?"까지 진행된다.

**NFR-09 저장·전송 고지**
- Given S1이나 S7에 있을 때, When 고지 영역을 열면, Then 음성은 외부로 전송돼 글자로 바뀐 뒤 저장되지 않고, 인식 텍스트만 이 기기에 저장된다는 문장을 볼 수 있다.
