|---|---|---|---|
| FR-01 | F1 | 마이크 버튼으로 아이의 질문을 녹음하고 텍스트로 인식한다. STT가 인식 후보를 여러 개 주면 모두 다음 단계로 넘긴다. | MVP |

| FR-04 | F2 | 후보가 1개면 확인 질문 화면(S3)에 단어와 힌트를 보여주고, 고정 문장 틀(2~3종)에 힌트를 붙인 모야 대사를 소리로 들려준다. (예: "저금통 말하는 거야? 돈을 모아 두는 통!") | MVP |

| FR-07 | F3 | 고른 단어의 쉬운 설명(한두 문장)과 영어 표기(있을 때)를 검수된 단어 데이터에서 단어 카드(S5)로 보여준다. 예문은 단어 데이터에만 두고 화면에는 보여주지 않는다(와이어프레임 기준). 사전 뜻 범위를 벗어난 내용은 데이터에 넣지 않는다. | MVP |

## 2. Non-Functional Requirements
| ID | 요구사항 |
|---|---|
| NFR-01 | 모바일 세로(375px) 기준으로, 모바일 Chrome과 Safari에서 동작한다. |
| NFR-02 | 질문이 끝나고 모야의 첫 반응까지 3초 이내 (잠정, API 연동 후 측정해 확정). 기다리는 동안 '생각 중' 상태를 보여준다. |
| NFR-03 | 외부 API 키는 서버 전용(.env.local)으로 두고, 클라이언트에 노출하지 않는다. |
| NFR-04 | 음성 원본은 저장하지 않고 인식 텍스트만 저장한다. 아이 음성은 인식을 위해 외부 STT로 전송되므로, 데이터를 보관하지 않거나 보관 기간이 명시된 STT를 고른다. 사용성 테스트(11/6) 전에 보호자 동의서를 확정한다 (녹음 테스트 양식 재사용). |
| NFR-05 | 단어 데이터에 없는 단어는 설명을 만들지 않는다. |
| NFR-06 | 욕설·성인용·폭력적인 단어를 물으면 설명하지 않고, "엄마·아빠한테 물어보자"로 안내한다. (판별 기준 TBD) |
| NFR-07 | 마이크 권한 거부·인식 실패 시 다시 말하기 경로를 준다. |
| NFR-08 | 접근성은 03_UX_UI_SPEC.md §4 규칙을 따른다. |
| NFR-09 | 무엇이 저장되고 어디로 전송되는지(음성은 글자로 바꾸는 데만 쓰고 저장 안 함, 인식 텍스트만 이 기기에 저장)를 보호자 화면(/parent)에서 확인할 수 있다. |

## 3. Acceptance Criteria (MVP)
**FR-01 음성 녹음·인식**
- Given S1에서 마이크 권한이 허용돼 있을 때, When 마이크 버튼을 누르고 말하면, Then 녹음이 끝난 뒤 인식 텍스트로 다음 단계(FR-02)를 진행한다.
- Given 녹음 중일 때, When [그만하기]를 누르면, Then 녹음을 멈추고 S1로 돌아간다.
- Given 음성인식 요청이 실패했을 때, When 오류 응답을 받으면, Then E2를 보여준다.
- Given STT가 인식 후보를 여러 개 돌려줬을 때, When 인식이 끝나면, Then 모든 후보 텍스트를 FR-02로 넘긴다.

**FR-02 대상 단어 추출**
- Given 인식 텍스트가 "공룡이 뭐야?"일 때, When 단어를 추출하면, Then 대상 단어는 "공룡"이다.
- Given "○○ 뭐야" 패턴이 없거나 텍스트가 비어 있을 때, When 추출에 실패하면, Then E2 "다시 말해줄래?"를 보여준다.

**FR-03 후보 생성**
- Given 단어 데이터에 "수박"이 있을 때, When 입력이 "두박"이면, Then 역규칙(ㄷ→ㅅ) 변형으로 "수박"이 거리 0의 후보가 된다.
- Given 입력과 거리 2 이하인 단어가 없을 때, When 후보를 만들면, Then 결과는 `unknown`이다.
- Given 거리 2 이하인 단어가 4개 이상일 때, When 후보를 만들면, Then 거리순 상위 3개만 남긴다.
- Given 인식 후보가 "두박이 뭐야", "두부가 뭐야" 두 개일 때, When 후보를 만들면, Then 두 대상 단어 각각의 결과를 합치고 같은 단어는 더 가까운 거리 하나만 남긴다.

**FR-04 확인 질문**
- Given 되묻기 화면(S12)에 후보가 1개일 때, When 링크 "단어 확인 질문 보기"를 누르면, Then S3에 단어와 힌트가 보이고 문장 틀 + 힌트 대사가 소리로 나온다.
- Given S3에서, When 아이가 [네, 맞아요]를 고르면, Then S5 단어 카드로 넘어간다.
- Given S3에서 다시 말하기를 아직 쓰지 않았을 때, When [아니에요]를 고르면, Then S1로 돌아가 한 번 더 말하게 한다. 다시 말하기를 이미 썼다면 FR-06으로 간다.

**FR-05 되묻기와 후보 고르기**
- Given 인식에 성공했을 때, When 결과가 나오면, Then 되묻기 화면(S12)이 보이고 결과에 맞는 버튼 하나만 보인다(후보 2~3개: [후보 단어 고르기], 1개: "단어 확인 질문 보기", 0개: "물어볼 단어 안내 보기").
- Given 가방과 가발이 둘 다 거리 1일 때, When S4가 열리면, Then 데이터 순서대로 가방, 가발 카드가 보인다.
- Given S4에서, When 카드를 누르면, Then 그 단어로 S5에 간다. [들어보기]는 소리만 내고 선택하지 않는다.
- Given S4에서, When [여기 없어요]를 고르면, Then FR-04와 같은 다시 말하기 규칙을 따른다.

**FR-06 물어볼 단어**
- Given 후보가 0개일 때, When 되묻기 화면에서 "물어볼 단어 안내 보기"를 누르면, Then S6을 보여준다.
- Given 다시 말하기를 쓴 뒤에도 [아니에요]나 [여기 없어요]를 골랐을 때, When 선택하면, Then S6을 보여준다.
- Given S6이 보일 때, When [내 단어장에 저장하기]를 누르면, Then 인식 텍스트를 물어볼 단어로 저장하고 버튼이 "적어 뒀어!"로 바뀌어 비활성이 된다. 누르지 않고 떠나면 저장하지 않는다. 저장에 실패하면 버튼이 "다시 저장하기"로 바뀌고 다시 누를 수 있다.

**FR-07 설명**
- Given 단어를 골랐을 때, When S5가 열리면, Then 그 단어 데이터의 쉬운 설명과 영어 표기(있을 때)를 보여준다. 예문은 보여주지 않는다.

**FR-08 음성 출력**
- Given 화면이 바뀔 때, When 모야의 대사가 바뀌면, Then 그 문장을 음성으로 읽고 보조기기 알림 영역(화면에는 보이지 않음)에 넣는다.
- Given 기기가 speechSynthesis를 지원하지 않을 때, When 대사가 나오면, Then 오류 없이 진행한다.

**FR-09 카드 저장**
- Given S5 단어 카드가 보일 때, When [내 단어장에 저장하기]를 누르면, Then FR-09의 필드를 가진 카드가 저장되고 버튼이 "저장했어!"로 바뀌어 비활성이 된다. 실패하면 "다시 저장하기"로 바뀐다.
- Given S5 단어 카드가 보일 때, When 저장 버튼을 누르지 않고 화면을 떠나면, Then 카드는 저장되지 않는다. (물어볼 단어도 S6에서 같은 방식, FR-06)
- Given 저장소 쓰기가 실패했을 때, When 저장을 시도하면, Then 화면이 깨지지 않고 버튼이 "다시 저장하기"로 바뀌며 흐름을 계속 진행한다.

**FR-10 단어장**
- Given 카드가 저장돼 있을 때, When S7을 열면, Then 단어 카드(상태 "새 단어")와 물어볼 단어가 목록으로 보이고, 새로고침해도 남아 있다.
- Given 카드가 저장돼 있을 때, When 칩 [복습 중]을 누르면, Then Select도 같은 값이 되고 카드 그리드가 비어 있다(반복 학습 베타).
- Given 저장된 것이 없을 때, When S7을 열면, Then 빈 상태 안내를 보여준다.
- Given 카드가 저장돼 있을 때, When S7에서 카드를 누르면, Then 카드 상세(S11, /app/cards/[id])가 보인다. 없는 id면 안내와 [단어 카드 목록으로]를 보여준다.

**FR-13 폴백**
- Given 마이크 권한이 거부됐을 때, When 음성 녹음 화면(S1)이 열리면, Then [녹음 시작] 아래에 텍스트 입력과 예시 단어가 보인다(E1). 마이크를 쓸 수 있으면 보이지 않는다.
- Given 텍스트 입력이나 예시 단어를 썼을 때, When 제출하면, Then FR-02부터 같은 흐름으로 진행한다.
- Given 예시 단어 버튼 [두박이 뭐야?]가 보일 때, When 누르면, Then 마이크 없이 되묻기(S12)를 거쳐 S3 "수박" 확인 질문까지 진행할 수 있다.

**NFR-09 저장·전송 고지**
- Given 보호자 화면(/parent)에 있을 때, When 화면을 보면, Then 음성은 외부로 전송돼 글자로 바뀐 뒤 저장되지 않고, 인식 텍스트만 이 기기에 저장된다는 문장을 볼 수 있다.
