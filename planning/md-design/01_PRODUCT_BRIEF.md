## 1. One-liner
아이의 서툰 발음도 되물어서 알아듣고, 모르는 단어를 아이 눈높이로 알려주는 외계인 친구 '모야'. 아이는 궁금한 단어를 그 자리에서 음성으로 물어 배운다.

- 세계관: 모야는 '지구 번역기'로 아이와 함께 지구 말을 배워가는 외계인 친구다.

## 2. Problem
| 대상 | 문제 | 근거 |
|---|---|---|
| 아이 | 사전은 글을 읽고 써야 해서, 글을 막 배우는 만 5~8세가 쓰기 어렵다. 글로 입력하면 그 단어를 어떤 상황에서 들었는지도 전하기 어렵다. | 만 5~8세는 글을 막 배우는 시기 |
| 음성 AI | 기존 음성 AI는 아이 말을 잘 못 알아듣는다. | 단어 오류율 성인 약 5%, 4~6세 최대 35% (영어권 종합, [The Learning Agency](https://the-learning-agency.com/guides-resources/closing-the-child-speech-recognition-gap-evidence-limitations-and-paths-forward/)). 국내 5~7세 AI 스피커 대화 실패율 31.6% ([홍정림·최보름, 2020](https://koreascience.kr/article/JAKO202022560454937.page)) |
| 부모 | 늘 곁에서 바로 답하기 어렵고, 아이 눈높이로 풀어 설명하기도 어렵다. | 교원 91.8%가 학생 문해력 저하를 체감 ([교총, 2024](https://www.hankookilbo.com/News/Read/A2024100709340000468)) |

## 3. Target User
| 구분 | 정의 |
|---|---|
| 사용자 | 글을 막 배우기 시작하는 만 5~8세 (유치원 7세반~초등 2학년) |
| 구매자 | 아이의 보호자 |
| 확장 | 다문화 가정, 해외 한인 가정 |

- **사용 순간:** 어른의 대화, TV, 책에서 모르는 단어를 들었을 때

## 4. Value
| 대상 | 가치 |
|---|---|
| 아이 | 궁금한 단어를 그 자리에서 해결하고, 모야에게 가르쳐주며 복습해 오래 기억한다. 가르칠 상대가 있으면 학습에 더 노력한다는 연구가 있다 ([Chase et al., 2009](https://eric.ed.gov/?id=EJ855299)). |
| 부모 | 아이가 무엇을 궁금해하는지 알고, 어휘 학습에 활용한다. |

### 차별점
핵심: 아이 발음이 부정확해도 모야가 되묻고, 단어를 들은 상황(TV, 책 등)을 단서로 삼아 아이가 의도한 단어를 찾아낸다.

| 대안 | 한계 | 모야 |
|---|---|---|
| AI 스피커 (클로바, 기가지니 등) | 아이 말 인식 실패가 잦다 | 발음 패턴과 되묻기로 단어를 유추한다 |
| 국어사전·초등 어휘 앱 | 글 입력이 필요하고, 교과 단어 위주 | 말로 묻고, 아이가 실제로 들은 단어로 단어장을 만든다 |
| 범용 AI 챗봇 (ChatGPT 등) | 약관상 만 13세 이상, 아동용 설계가 아니다 | 아이 눈높이 설명, 부모 리포트 |
| Ello (해외 아동 음성 AI) | 영어 읽기 코치, 모르는 단어 질문용이 아니다 | 한국어, 직접 들은 단어 질문에 집중 |

## 5. Scope
| 구분 | 범위 |
|---|---|
| 이번 (해커톤 MVP) | F1 음성으로 묻기, F2 되묻기로 단어 찾기, F3 단어 카드. 모바일 웹 배포. 외부 API는 음성인식 하나만 쓴다. |
| 다음 (베타) | F4 모야와 반복 학습, F5 부모 리포트. 해커톤에서는 여유가 있으면 간단한 버전만 만든다. |
| 제외 | 결제·구독, 회원가입·복잡한 인증, 아이 음성 원본 저장, 자체 아동 음성인식 모델, 유치원 교실 모드, B2B API, 다국어 리포트 |
