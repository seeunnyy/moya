# PRD.md

## Problem
- 아이는 모르는 단어를 들으면 바로 알고 싶지만, 사전·검색은 철자를 알아야 쓸 수 있다.
- 기존 음성 AI는 아이 말을 잘 못 알아듣는다. (국내 5~7세 AI 스피커 대화 실패율 31.6%)
- 부모는 늘 곁에서 아이 눈높이로 바로 설명해주기 어렵다.

## Target User
- 사용자: 글을 막 배우기 시작하는 만 5~8세 (유치원 7세반~초등 2학년)
- 구매자: 아이의 보호자
- 확장: 다문화 가정, 해외 한인 가정

## Core Value
서툰 발음도 되물어서 알아듣고, 아이가 실제로 들은 단어를 그 자리에서 아이 눈높이로 알려준다.

## Core Features
### MVP
1. 음성으로 묻기: 모야에게 모르는 단어를 음성으로 묻는다.
2. 되묻기로 단어 찾기: 발음이 부정확하면 후보 2~3개를 보여주고 고르게 한다.
3. 단어 카드: 뜻, 예문, 들은 상황, 아이가 처음 말한 발음을 카드로 저장한다.

### 2순위
4. 모야와 반복 학습: 1·3·7일 뒤 모야가 단어를 다시 묻고, 아이 설명을 사전 뜻과 비교해 칭찬·보충한다.
5. 부모 리포트: 이번 주 물어본 단어 학습 기록을 정리해 보여준다.

## Non-goals
- 결제·구독
- 회원가입·복잡한 인증
- 아이 음성 원본 저장
- 자체 아동 음성인식 모델 학습 (장기 로드맵)
- 유치원 교실 모드, B2B API, 다국어 부모 리포트

## Success Criteria
- 11/5 1차 배포 URL에서 핵심 시나리오(묻기 → 되묻기 → 카드 저장)가 끝까지 동작한다.
- 사용성 테스트(11/6~11/12)에서 아이가 되묻기 후보 중 원하는 단어를 고를 수 있다.
- 단어 설명이 사전 뜻 범위를 벗어나지 않는다.
